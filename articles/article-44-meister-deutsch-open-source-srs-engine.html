Meister-Deutsch: Open-Source Horticultural German SRS & Phonetic Engine

Published: 2026-09-01 • Author: Inwoo Hwang • Reading Time: 8 min

Mastering technical German for the prestigious *Gärtnermeister* (Master Horticulturalist) examination requires retaining intricate compound nouns (e.g. *die Dampfdrucksättigung*, *das Blockheizkraftwerk*). We open-source Meister-Deutsch SRS, a lightweight Web application implementing SuperMemo SM-2 spaced repetition algorithms, colorblind-accessible gender markers (🔵 der / 🔴 die / 🟡 das), and Web Speech API phonetic rendering.

1. The SM-2 Interval Function

I(n) = I(n-1) \times EF, \quad EF' = EF + (0.1 - (5 - q) \times (0.08 + (5 - q) \times 0.02))
