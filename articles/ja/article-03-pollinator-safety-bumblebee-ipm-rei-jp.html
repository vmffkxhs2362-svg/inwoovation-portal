1. 振動受粉（バズ・ポリネーション）の生物物理学と温湿度・飽差 (VPD) 限界

トマト・ナス・ピーマンなどのナス科果菜類や促成イチゴ栽培において、マルハナバチ（Bombus terrestris / Bombus ignitus）による生物受粉は着果安定と果実肥大（種子形成に伴うオーキシン合成）の要です。トマトの葯（やく）は先端の小孔から花粉を放出する孔開葯構造を持つため、マルハナバチが大顎で葯筒を噛み締めながら飛翔筋を 250〜400 Hz で高速振動させる「バズ・ポリネーション（振動受粉）」によってのみ効率的な受粉が成立します。

最適訪花微気象レンジ： 気温 18.0〜26.0 ℃  |  相対湿度 55〜75 %  |  飽差 (VPD) 0.65〜1.25 kPa
高温障害閾値： 花器温度 > 30.0 ℃ が4時間以上継続すると花粉稔性・発芽率が 60% 以上低下

温室内の相対湿度が 80% を超える（VPD < 0.45 kPa）と、吸湿性の高い花粉粒が葯筒内部で凝集して放出されなくなります。逆に相対湿度が 50% 未満（VPD > 1.50 kPa）の過乾燥状態では柱頭粘液が乾燥し、付着した花粉管の伸長が阻害されます。1箱のコロニー（働きバチ60〜80頭）あたりの適正導入面積は大玉・中玉トマトで 1,500〜2,500 m²、ミニトマトで 1,000〜1,500 m² が基準となります。

2. 温室ガラスの紫外線遮蔽による農薬分解半減期 (DT50) の延長と一次減衰方程式

天敵製剤（ツヤコバチ類 Encarsia formosa ・カブリダニ類 Amblyseius swirskii / Phytoseiulus persimilis）およびマルハナバチ（Bombus terrestris）を併用する IPM（Integrated Pest Management：総合的病害虫管理）体系において化学農薬や微生物農薬を散布する場合、葉面上の有効成分残留量 C(t) [mg · kg⁻¹] は一次反応速度論（First-Order Decay Kinetics）に従って減衰します：

C(t) = C₀ · exp( − k_deg · t )   |   分解速度定数 k_deg [d⁻¹] = ln(2) / DT₅₀ = 0.6931 / DT₅₀
天敵・ハチ再導入可能日数 t_safe [days] = ( DT₅₀ / 0.6931 ) · ln( C₀ / C_NOEC )

ここで極めて重要な工学的注意点は、温室内（Glasshouse / Plastic Tunnel）では露地栽培（Open Field）と比較して農薬の光分解半減期 DT₅₀ (Half-Life) が 1.5 〜 2.8 倍に長期化するという事実です。一般的なフェンロー型温室のフロートガラス（厚さ 4.0 mm）や UV カット農POフィルムは波長 280 〜 315 nm の高エネルギー紫外線（UV-B 領域）を 85 〜 99 % 遮断するため、紫外線による光加水分解（Photolysis）が大幅に遅れ、また降雨による洗い流し（Rain Wash-off）や強風による揮散（Volatilization）も発生しないためです。例えば露地での DT₅₀,field = 2.5 days の薬剤であっても、冬季の日射量が低い温室内では実効半減期が DT₅₀,gh = 5.5 〜 7.0 days まで延長することを前提に安全待機期間（Side-Effect Persistence Period）を設計しなければなりません。

3. 巣箱の一方通行ゲート（帰巣専用シャッター）操作と影響日数マトリクス

薬剤散布（Foliar Spraying / Fogging）を実施する前日には、必ずマルハナバチ巣箱（Hive Box）の出入口を「帰巣専用（In-Only Gate / One-Way Entrance）」モードに切り替え、外勤バチ（Foragers）が全て巣内に戻った日没後にシャッターを完全閉鎖して温室外部の涼しい暗所（温度 15.0 〜 20.0 ℃、相対湿度 60 〜 70 %）へ一時退避させます。退避時間が 24 時間を超える場合は、巣箱内部の付属砂糖水タンク（Sucrose Solution Feeder: 糖度 50 〜 60 %）のバルブが確実に開放されているか、および花粉団子（Pollen Patty: 1 コロニーあたり 20 〜 30 g / day）が不足していないかを点検します。

薬剤カテゴリー (IOBC Class) マルハナバチ・天敵への作用機序 (Mode of Action) 巣箱退避・ゲート閉鎖プロトコル (Hive Protocol) 標準的な再導入待機期間 (Wait Time)
Class 1: 微生物殺虫剤・選択性殺菌剤 (無害) 直接的な神経毒性なし（展着剤・気門封鎖剤のみ物理的注意） 散布中のみゲート閉鎖（直接噴霧被曝の防止） 散布液乾燥後（2 〜 6 hours）
Class 2: IGR（昆虫成長制御剤）・一部殺ダニ剤 成虫への急性毒性は低いが幼虫脱皮・卵ふ化を強く阻害 前日夕方に帰巣ゲート閉鎖・巣箱を温室から一時搬出 1 〜 3 days（花粉汚染減衰後）
Class 3: スピノサド・マクロライド系剤 (中程度影響) 葉面乾固後は安全性が高まるが散布直後の接触毒性は大 巣箱を完全搬出し、天窓強制換気後に再設置 3 〜 7 days（UV透過率に依存）
Class 4: 浸透移行性ネオニコチノイド・ピレスロイド 花蜜 (Nectar)・花粉 (Pollen) へ長期間移行しコロニー崩壊を誘発 マルハナバチ導入作型では原則使用不可（定植前灌注も注意） 14 〜 60 days 以上（使用回避）

4. 作業者再入場待機期間 (REI) と天窓パージ換気回数 (ACH) の安全設計

農薬散布後の作業者（摘芽・誘引・葉かき・収穫スタッフ）の経皮吸収（Dermal Absorption）および吸入曝露（Inhalation Exposure）を防ぐため、再入場待機期間（Restricted-Entry Interval: REI, 通常 12 〜 48 hours）中は防護服（PPE）なしでの入室を厳禁とします。再入場前には、温室気積 V_gh [m³] に対して最低 4 〜 6 回分（積算換気回数 N_purge = ACH × t_vent ≥ 6.0） の天窓強制・自然換気を実施し、気相中に揮発した農薬蒸気圧濃度 C_air(t) = C_air,0 · exp( − ACH · t ) を作業環境許容濃度以下にパージする必要があります。

施設園芸エンジニアリング 実践FAQ

Q1: トマトの花でマルハナバチが正常に訪花しているかを見分ける方法は？
マルハナバチが振動受粉を行う際、大顎で葯筒を噛むため、訪花から2〜4時間以内に黄色い葯筒の表面に褐色の「バイトマーク（噛み跡）」が現れます。開花中の花にこの褐色マークが80%以上確認できれば受粉は順調です。

Q2: なぜ温室内では露地よりも農薬の天敵影響日数（残留期間）が長くなるのですか？
温室の被覆ガラスやフィルムが農薬分子を光分解する高エネルギーの紫外線（UV-B）を遮断することに加え、降雨による葉面からの洗い流しがないため、分解半減期 (DT50) が露地の1.5〜2.8倍に延びるためです。

Q3: 夏季の高温期にマルハナバチの訪花活動が低下する原因と対策は？
室温が30℃を超えるとマルハナバチは巣箱内の幼虫を冷却するための羽ばたき（ファンニング）に専念し、訪花に出なくなります。巣箱を直射日光の当たらない通路下部に配置し、高圧細霧冷房等で日中気温を28℃以下に抑えることが有効です。
