1. 完全人工光型植物工場（PFAL）の閉鎖系熱・水分収支と顕熱比（SHR = Qs / Qtot）の逆転現象

千葉大学の古在豊樹（Toyoki Kozai）らによって工学体系が確立された完全人工光型植物工場（PFAL: Plant Factory with Artificial Lighting / 垂直農業 Vertical Farming）は、太陽光利用型温室とは熱力学的な境界条件が根本的に異なります。硬質ウレタンフォーム断熱パネル（熱貫流率 U ≤ 0.18〜0.24 W · m⁻² · K⁻¹）で構築され、気密性が極めて高い閉鎖型栽培室（自然換気回数 N < 0.01〜0.02 h⁻¹）では、外壁を通じた熱貫流や隙間風の影響は全負荷の 3% 未満に過ぎません。その代わり、多段栽培棚に高密度実装された LED 照明器具・電源ドライバ・循環ファン・養液ポンプへ投入される電気エネルギー Pelec,in のうち、光合成によって炭水化物の化学結合エネルギー（約 17.5 MJ · kg⁻¹ DW）として固定されるのはわずか 1.0〜2.2% であり、残りの 98% 以上 が栽培室内部で顕熱（Sensible Heat: Qs）または蒸散潜熱（Latent Heat: QL）へと変換されます。

商業用 PFAL の空調設計において最も多くの失敗事例を生んできた原因は、「LED 投入電力 ＝ そのまま顕熱冷房負荷になる」と誤認し、オフィスビルや店舗用の汎用パッケージエアコンを選定してしまうことにあります。確かに最新の高効率園芸用 LED（PPE = 3.2〜3.8 µmol · J⁻¹、電力・光放射変換効率 ηPAR ≈ 0.58〜0.68）では、投入電力の 32〜42% が LED 基板および電源ドライバからの直接顕熱放散となります。しかし、残りの 58〜68% として照射された PAR 光放射エネルギーの大半は葉群（LAI ≥ 3.0〜4.5）に吸収され、気孔からの活発な水蒸気蒸散を駆動して相変化潜熱（22 °C における水の蒸発潜熱 λv ≈ 2,449 kJ · kg⁻¹）へと形態転換します。

閉鎖型栽培室の定常全熱負荷： Qtot = PLED · (1 − ηchem) + Pfan,pump + Qenv ≈ Qs + QL   [kW]
作物蒸散による潜熱負荷： QL = ṁtrans · λv   [kW]   （ṁtrans [kg H2O · s−1], λv ≈ 2449 kJ · kg−1）
室内顕熱負荷（エネルギー保存差）： Qs = Qtot − QL   [kW]
室内顕熱比（Sensible Heat Ratio）： SHR = Qs / Qtot = Qs / (Qs + QL)
明期（成株 LAI ≥ 3.2）： SHR = 0.32 〜 0.45 ｜ 暗期（LED 消灯時）： SHR = 0.05 〜 0.15

オフィス・商業建築用の標準パッケージ空調機は、人体顕熱とOA機器発熱を主対象とするため SHR = 0.75〜0.85（全冷却能力の約8割が温度低下、2割のみが除湿）となるよう蒸発器伝熱面積と送風量が設計されています。この汎用機を SHR = 0.38 の PFAL に設置すると、水蒸気（潜熱）を半分も除去できていない段階で室温だけが設定値（例：22.0 °C）に到達してサーモオフ（圧縮機停止またはインバータ最低回転）に陥ります。その結果、室内相対湿度は瞬く間に 88〜96% RH（VPD < 0.25 kPa）へ暴走し、天井・ダクト結露、灰色かび病・軟腐病の蔓延、および Ca2+ 輸送停止による全面的なチップバーンを引き起こします。

定量設計ベンチマーク（実栽培面積 6,000 m² 商業用リーフレタス PFAL）： 床面積 1,000 m² に 10 段栽培棚（有効栽培面積 Acrop = 6,000 m²）を配置し、PPFD = 220 µmol · m⁻² · s⁻¹・システム効率 PPE = 3.3 µmol · J⁻¹ で照射する場合、LED 総消費電力は P_LED = (6000 × 220) / 3.3 = 400 kW（補機ファン含め全熱負荷 Q_tot ≈ 418 kW）となります。成株群落の蒸散速度が ṁ_trans = 0.068 kg · m⁻² · h⁻¹ のとき、工場全体の蒸散水量は毎時 408 kg · h⁻¹（16時間明期で約 6,530 L）に達し、潜熱負荷は Q_L = (408 / 3600) × 2449 = 277.6 kW、顕熱負荷は Q_s = 418 − 277.6 = 140.4 kW、すなわち要求顕熱比は SHR = 140.4 / 418 = 0.336 となります。

2. 湿り空気線図（Psychrometric Chart / Mollier h–x 線図）による状態点設計と物質・エンタルピー収支

空気調和・衛生工学会（SHASE）および ASHRAE Fundamentals の湿り空気熱力学に基づき、標準大気圧 Patm = 101.325 kPa における乾き空気 1 kg あたりの絶対湿度 x [kgw · kgda−1]、比エンタルピー h [kJ · kgda−1]、および状態変化プロセスを厳密に定式化します。

水蒸気分圧： ev = (RH / 100) · 0.61078 · exp[ (17.2694 · T) / (T + 237.29) ]   [kPa]
絶対湿度（混合比）： x = 0.62198 · [ ev / (Patm − ev) ]   [kgw · kgda−1]
湿り空気比エンタルピー： h = cpa · T + x · (r0 + cpv · T) ≈ 1.006 · T + x · (2501 + 1.86 · T)   [kJ · kgda−1]
必要循環乾き空気質量流量： ṁda = ṁtrans / (xRA − xSA) = Qs / [ cpm · (TRA − TSA) ]   [kgda · s−1]
装置状態線勾配（エンタルピー水分比）： Δh / Δx = Qtot / ṁtrans = λv / (1 − SHR)   [kJ · kgw−1]

具体例として、明期の栽培棚目標環境を室温 T_RA = 23.0 °C、相対湿度 RH_RA = 74.0%（飽差 VPD_air = 0.73 kPa、露点温度 T_dp = 18.1 °C）とし、室内負荷が SHR = 0.36 である場合の専用空調機（AHU）内部の3段階空気状態プロセスを追跡します。

  1. 状態点 1（栽培棚還気 Return Air: RA）： 乾球温度 T_1 = 23.0 °C、相対湿度 RH_1 = 74.0%、絶対湿度 x_1 = 13.06 g · kg_da⁻¹（0.01306 kg · kg_da⁻¹）、比エンタルピー h_1 = 56.40 kJ · kg_da⁻¹。
  2. 状態点 2（冷却除湿コイル出口 Off-Coil / Apparatus Dew Point）： 7.0 °C 往・12.0 °C 還の冷水コイル（または直膨蒸発器）を通過させ、露点温度より十分低い T_2 = 11.5 °C（RH_2 = 96.0%）まで過冷却減湿します。このとき絶対湿度は x_2 = 8.12 g · kg_da⁻¹、比エンタルピーは h_2 = 32.04 kJ · kg_da⁻¹ まで低下し、乾き空気 1 kg あたり Δx = 13.06 − 8.12 = 4.94 g の水蒸気が凝縮ドレン水として除去されます（コイル全熱除去量 Δh_12 = 24.36 kJ · kg_da⁻¹）。
  3. 状態点 3（再熱器出口・栽培棚給気 Supply Air: SA）： もし状態点 2 の 11.5 °C・RH 96% の冷気をそのまま多段棚へ吹き出すと、室内顕熱に対して過冷却となり（吹出温度差 ΔT = 11.5 K によるコイル見かけ SHR ≈ 0.48 > 室内要求 0.36）、給気ダクト外面結露と吹出口直近株の低温障害を招きます。そこで絶対湿度 x_3 = x_2 = 8.12 g · kg_da⁻¹ を保ったまま等絶対湿度再熱（Sensible Reheat）を行い、給気状態を T_3 = 16.0 °C、RH_3 = 71.5%、h_3 = 36.60 kJ · kg_da⁻¹ へ調整します。これにより室内への正味有効エンタルピー差は h_1 − h_3 = 19.80 kJ · kg_da⁻¹、そのうち正味顕熱差は 1.02 · (23.0 − 16.0) = 7.14 kJ · kg_da⁻¹ となり、比率 7.14 / 19.80 = 0.361 が室内の要求顕熱比 SHR = 0.36 と完全一致します。

3. 再熱除湿サイクルの熱力学比較とシステム COP 最適化（ホットガス再熱・顕熱熱交換・水冷式 LED）

PFAL の総生産原価のうち電力費は 25〜35% を占め、その内訳は LED 照明が約 60〜70%、空調・除湿設備が約 22〜32% です。従来型植物工場では L-COP（照明電力に対する空調電力の逆数指標）または空調システム総合成績係数 COPHVAC,sys が 2.5〜3.2 に留まっていましたが、最新の熱回収アーキテクチャを組み合わせることで COP_HVAC,sys = 5.0〜7.8 への飛躍的省エネが可能です。

  • 電気ヒータ再熱の厳禁： 状態点 2 → 3 の再熱に電気シーズヒータを使うと、1 kW の再熱を行うために 1 kW の高品質電力（エクセルギー）を投入したうえ、その 1 kW 分を再び冷凍機で冷却しなければならず、実効除湿効率（SMER: Specific Moisture Extraction Rate）が 1.1〜1.5 kg · kWh⁻¹ まで暴落します。
  • ホットガス・バイパス再熱（Hot-Gas Reheat Dedicated Outdoor/Indoor Air System）： 蒸気圧縮冷凍サイクルの圧縮機から吐出される高温高圧冷媒ガス（R32 / R1234ze(E)、55〜75 °C）を室外凝縮器ですべて大気放熱するのではなく、三方比例制御弁で室内冷却コイル後段の再熱コンデンサへ分岐させます。本来屋外に捨てていた凝縮排熱を無料で再熱源に転用し、しかも冷媒過冷却度（Subcooling）が増大して蒸発器エンタルピー差が広がるため、追加消費電力ゼロで SHR = 0.05〜0.80 の無段階連続制御を実現します（SMER = 2.6〜3.4 kg · kWh⁻¹）。
  • ラップアラウンド・ヒートパイプ／直交平板型顕熱熱交換器（Run-Around / Plate Sensible Heat Recovery）： 冷却除湿コイルの上流（高温還気 23.0 °C）と下流（過冷却空気 11.5 °C）を直交アルミ平板熱交換器または二相サーモサイフォン・ヒートパイプで熱結合します。ファン静圧損失わずか 80〜140 Pa のみで還気が 23.0 → 17.8 °C へ無料予冷（Pre-cooling）され、同時にコイル出口空気が 11.5 → 16.7 °C へ無料再熱（Re-heating）されます（温度交換効率 εs = 0.45〜0.58）。これにより冷凍機自体の所要冷却容量を 20〜28% 直接削減できます。
  • 水冷式 LED（Water-Cooled LED Luminaires）＋冬季フリークーリング統合： そもそも室内で SHR の不均衡や空調負荷増大が起きる一因は、LED 素子ジャンクションおよび電源ドライバの顕熱を「いったん室内空気へ放散してから空気冷却で回収する」点にあります。LED アルミヒートシンク内部に冷却水チャンネルを設け、24〜28 °C の循環水で顕熱の 60〜75% を直接屋外のドライクーラ／密閉式冷却塔へ排熱（または冬季温室・事務所暖房へ熱回収）すれば、空調機送風量を半減でき、外気温 12 °C 以下の季節にはチラー圧縮機を停止するフリークーリング（COP > 12〜18）との相乗効果で年間空調電力を 45〜55% 削減できます。

4. 多段栽培棚（10〜16段ラック）の CFD 微気象均一化設計とチップバーン（縁腐れ症）根絶工学

空調機（AHU）出口でどれほど理想的な温湿度（例：T = 22.0 °C, RH = 72%, VPD = 0.74 kPa）を作り出しても、高さ 6〜10 m・棚段数 10〜16段・1段あたりの垂直クリアランスわずか 280〜380 mm という超高密度多段ラック内部へ均一に空気を届けられなければ商業生産は成立しません。天井アネモスタットからの一括吹出方式では、冷気ジェットが抵抗の小さい通路（アイル）空間のみを下降して還気口へ短絡（ショートサーキット）し、奥行 1.2〜1.8 m・長さ 15〜30 m の栽培ベッド中央部では風速 u < 0.06 m · s⁻¹ の完全死水域（Stagnant Dead Zone）が形成されます。その結果、最上段と最下段で ΔT_vert = 3.5〜5.0 K もの熱成層（Thermal Stratification）が生じ、生育速度と収穫適期が段ごとにバラバラになります。

さらに深刻な生理障害が、リーフレタス・結球レタス・イチゴの高収量運転（PPFD ≥ 220 µmol · m⁻² · s⁻¹、CO2 ≥ 1,000 ppm）において商品価値を一夜にして全滅させるチップバーン（Tipburn：新葉縁部のカルシウム欠乏壊死）です。カルシウムイオン（Ca2+）は篩管（Phloem）を移動できず、100% 木部道管（Xylem）の蒸散流マスフローに乗ってのみ輸送されます。ロゼット中心の成長点（メリステム）を包む若い内葉は外気から遮蔽されているため、無風下では局所境界層の相対湿度が 96〜99% に達して局所蒸散がゼロとなり、根圏養液に十分な Ca2+ が存在していても成長点細胞壁への Ca2+ フラックスが途絶えて 36〜48時間以内 に細胞崩壊を発症します。

CFD 群落多孔質媒体（Darcy-Forchheimer）運動量シンク項：
  Si = − [ (μ / αperm) · ui + CD · LAD · ρair · |u| · ui ]   [N · m−3]
多孔ダクト静圧回復（Static Pressure Regain）設計式：
  ΔPduct(z) = P0 + (ρair / 2) · [ vin2 − v(z)2 ] − ∫0z (fD / Dh) · (ρair · v2 / 2) dz
多段栽培棚 CFD 合格基準（KPI）：
  群落面風速 ucanopy = 0.35 〜 0.65 m · s−1 ｜ 全段温度標準偏差 σT ≤ 0.45 K（最大幅 ±0.8 K） ｜ ΔVPD ≤ ±0.10 kPa

ここで LAD [m2 · m−3] は葉面積密度（Leaf Area Density）、CD（レタス群落で 0.20〜0.32）は葉群抗力係数です。3次元定常 RANS（k-ω SST または Realizable k-ε 乱流モデル）を用いた最新の多段棚気流設計では、以下の3原則を標準実装します。

  1. 各段独立マイクロパンチング・エアソックス／スリットチューブ給気（Per-Tier Micro-Perforated Ducting）： 天井一括吹出を廃止し、すべての栽培段のLED照明バー間（またはベッド両側面）に難燃ポリエステル製マイクロパンチングダクト（孔径 1.5〜4.0 mm、レーザー穿孔）を敷設します。ダクト上流から末端へ向けて流速低下に伴う静圧上昇（ベルヌーイの静圧回復）が生じるため、長手方向の位置 z に応じて開口率を段階的に変化させるテーパ穿孔設計により、24 m 棚の始端から終端まで吹出風量偏差を ±6% 以内 に抑え込みます。
  2. 成長点直撃の鉛直下方気流（Vertical Downward Jet Targeting Meristem）： 千葉大学・アリゾナ大学（Zhang & Kacira, 2020）の実証研究により、水平横風よりも照明面から株中心の成長点へ向かって鉛直下方（0.40〜0.60 m · s⁻¹）に微風を吹き下ろす方式の方が、内葉ロゼット内部の静止境界層を効率よく破壊し、同等の総送風量でもチップバーン発生率を 85% → 2% 未満 へと劇的に抑制できることが証明されています。
  3. 通路排気リターン分離（Hot/Humid Aisle Containment）： データセンターのコールドアイル／ホットアイル分離と同様に、棚内を通過して顕熱と水蒸気を吸収した空気を背面または側面リターンダクトから直接 AHU へ吸い込み、給気と還気の再混合（ショートサーキット）を遮断します。

🔥 施設外皮熱損失・断熱U値＆空調熱負荷インタラクティブ計算機

栽培施設面積・内外温度差・外皮断熱仕様（高断熱パネル〜複層被覆）を調整し、外皮貫流熱負荷（kW）と空調・ヒートポンプ容量バランスをリアルタイムに検証できます。

5. 暗期等温除湿シーケンス・クリーンルーム陽圧制御（+15 Pa）・凝縮ドレン水完全循環再利用

商業スケール PFAL の連続安定稼働（年間 365 日・無農薬栽培）を完成させるためには、定常明期計算に加えて以下の3つの動的・衛生プロセス設計が不可欠です。

  • 明期→暗期遷移時の「消灯結露スパイク」防止制御： 全棚の LED を一斉消灯すると、顕熱入力 Qs は 1 秒でゼロになる一方、作物の気孔閉鎖には 10〜25分 の生理的時定数遅れがあるため蒸散 QL が継続し、同時に室温設定値を暗期温度（例：23 °C → 19 °C）へ急降下させると空気の飽和蒸気圧が低下して相対湿度が一気に 98〜100%（葉面結露）へ到達します。これを防ぐには、(1) 栽培区画を 2〜3 ブロックに分割して明暗周期を逆位相で平準化（契約電力デマンドピークも 40% 削減）し、(2) 消灯前 30分間 の段階調光（Dimming Ramp-Down）と消灯後 45分間 のホットガス最大再熱除湿モードをプリプログラムします。
  • ISO クラス 8 相当の陽圧クリーンルーム微差圧維持（ΔP = +10 〜 +20 Pa）： 外部からのアザミウマ・アブラムシ・コナジラミおよび糸状菌胞子の侵入を物理的に完封しつつ、1,000〜1,200 ppm に維持した高濃度 CO2 の漏出を最小化するため、エアシャワー前室に対して栽培室を常時 +15 Pa 前後の陽圧に保ちます。外気取入（OA）は必要最小限の CO2 保安換気量に絞り、中性能フィルタ（MERV 14 / F8）＋ HEPA フィルタを経由させます。
  • 凝縮除湿水の重金属フリー回収と養液原水へのクローズドループ統合： 前述の通り、PFAL では投入灌水量の 95〜97% が蒸散水蒸気となって空調冷却コイル上で再凝縮します。一般空調用の銅管・未処理アルミフィン熱交換器では弱酸性の凝縮水（溶存 CO2 により pH 5.2〜5.7）に銅イオン（Cu2+）やアルミニウムイオン（Al3+）が微量溶出し、水耕根系に薬害（根端褐変）を及ぼす事例が報告されています。植物工場専用コイルには親水性エポキシ／カチオン電着防食コーティングまたは SUS316L ステンレス伝熱管を指定し、回収ドレン水（EC < 0.02 dS · m⁻¹）を活性炭・限外ろ過膜（UF）および 254 nm UV-C 紫外線殺菌リアクタ（照射線量 ≥ 40 mJ · cm⁻²）で処理して養液調合タンクへ戻すことで、水利用効率 WUE = 0.96〜0.98（露地比約 40 倍の節水）を達成します。

6. 植物工場（PFAL）空調・環境制御エンジニアのための実務 FAQ

Q1. なぜ完全人工光型植物工場（PFAL）にオフィス・店舗用の汎用パッケージエアコンを導入すると湿度制御が破綻するのですか？

商業ビル・オフィス用の汎用パッケージ空調機は顕熱比（SHR = 顕熱能力 / 全熱能力）が 0.75〜0.85 となるよう蒸発器温度と風量が設計されています。これに対し、葉面積指数（LAI ≥ 3.0）に達した完全人工光型植物工場では、投入した LED 照明電力の 55〜68% が作物の蒸散によって水蒸気の潜熱（蒸発潜熱 約 2,449 kJ·kg⁻¹）へと変換されるため、明期の室内負荷の顕熱比 SHR は 0.32〜0.45、暗期（消灯時）には 0.05〜0.15 まで低下します。汎用エアコンでは潜熱除湿が完了する前に室温だけが設定温度に達してサーモオフ（圧縮機停止）してしまうため、室内相対湿度が 90% 以上に暴走し、結露・灰色かび病・チップバーンを引き起こします。

Q2. 過冷却除湿後の再熱（Reheat）において、電気ヒータではなくホットガス再熱や直交平板型顕熱熱交換器を採用すべき熱力学的理由は何ですか？

露点温度以下（例：11.5 °C）まで冷却除湿した空気を電気ヒータで吹出温度（16.0〜19.5 °C）へ再加熱すると、電気ヒータの投入電力自体が新たな室内顕熱負荷となり、冷却電力と加熱電力の二重損失によって実効除湿 COP が 1.4〜2.0 まで悪化します。圧縮機吐出高温冷媒ガスを室内再熱コイルへバイパスするホットガス・リヒート方式や、冷却コイル前後の還気と低温空気の間で顕熱のみをパッシブ交換するラップアラウンド・ヒートパイプ／直交平板型顕熱熱交換器（温度交換効率 45〜58%）を用いれば、追加の加熱電力をゼロに抑えつつ装置全体の見かけの SHR を 0.32〜0.42 へ自在に整合でき、システム COP を 3.8〜5.8 以上に維持できます。

Q3. 10段以上の多段栽培棚においてリーフレタスやイチゴに発生するチップバーン（縁腐れ症）を CFD 気流設計でどのように防止しますか？

チップバーンは根圏のカルシウム不足ではなく、高 PPFD・高 CO2 による急速成長下で結球・ロゼット中心の成長点（メリステム）周辺の静止境界層が飽和湿度に達し、木部道管の蒸散流に乗った Ca2+ イオン輸送が局所停止することで 36〜48 時間以内に発症します。天井吹出のみの空調では冷気が通路（アイル）へ短絡し、棚間隔 28〜38 cm の棚中央部で風速 0.08 m·s⁻¹ 未満の死水域が生じます。これを根絶するには、各段ごとにマイクロパンチング・エアソックス（微細多孔ダクト）または鉛直下方吹付けノズルを配置し、全段・全長にわたり成長点近傍で風速 0.35〜0.65 m·s⁻¹、上下段温度偏差 ±0.8 K 以内を確保する CFD 設計が不可欠です。

Q4. 完全人工光型植物工場（PFAL）における凝縮除湿水の回収量はどの程度になり、水利用効率（WUE）にどう寄与しますか？

閉鎖度が高い PFAL（換気回数 N < 0.015 h⁻¹）では、灌水として供給された養液水分のうち作物の生体新鮮重として収穫物に固定されるのは約 3〜5% に過ぎず、残りの 95〜97% は気孔から蒸散して室内空気中へ放出されます。実栽培面積 6,000 m²（LED 投入電力 400〜420 kW）規模の工場では、空調冷却コイルから 1 日あたり約 7,000〜8,500 L の低 EC 凝縮水（EC < 0.03 dS·m⁻¹）が回収されます。防食コーティングまたは SUS316L 熱交換器で銅・アルミ溶出を防ぎ、UF 膜ろ過および 254 nm UV-C 殺菌（40 mJ·cm⁻² 以上）を経て原水タンクへ循環再利用することで、露地栽培の 30〜50 倍に達する水利用効率（水回収率 96〜98%）を達成できます。
