1. 温室ピーク暖房負荷の物理モデル：貫流熱損失 (Q_trans) と隙間換気熱損失 (Q_inf)

フェンロー型連棟ガラス温室（Venlo Glasshouse）および高軒高プラスチックハウスにおける冬季ピーク暖房負荷（Peak Heating Load: Q_tot [W]）は、単純な床面積（A_floor [m²]）あたりの経験値ではなく、外皮被覆面積（A_cov [m²]）を通じた熱貫流損失（Transmission Heat Loss: Q_trans）、構造材の隙間を通じた隙間換気熱損失（Infiltration Heat Loss: Q_inf）、および土壌への地中伝導熱損失（Ground Conduction Loss: Q_ground）の総和として厳密に定式化されます（DIN V 18599 / EN 13031-1 / ASABE EP406.4 準拠）：

Q_tot [W] = Q_trans + Q_inf + Q_ground
Q_trans [W] = Σ ( U'_i [W · m⁻² · K⁻¹] × A_cov,i [m²] ) × ( T_in − T_out,design ) × ( 1 − η_screen )
Q_inf [W] = ( c_p,air · ρ_air / 3,600 ) × V_house [m³] × N_ach [h⁻¹] × ( T_in − T_out,design ) ≈ 0.34 × V_house × N_ach × ΔT

ここで T_in [℃] は目標室内設定温度（例：ハイワイヤートマト夜温 16.0 〜 18.0 ℃、パプリカ 18.5 ℃）、T_out,design [℃] は地域別の冬季設計用外気最低温度（例：つくば・北関東 − 6.0 ℃、北海道 − 15.0 ℃、オランダ Westland − 10.0 ℃、ドイツ北ライン＝ヴェストファーレン − 12.0 ℃）、V_house [m³] は温室気積、N_ach [h⁻¹] は天窓全閉時の自然隙間換気回数（Air Changes per Hour）を表します。空気の容積比熱 c_p,air · ρ_air / 3,600 は標準状態で約 0.34 W · h · m⁻³ · K⁻¹ となります。

2. 被覆材の熱貫流率 (U'値) と風速依存境界層・長波長放射冷却 (Sky Radiation)

一般建築用の垂直窓ガラスと異なり、温室の屋根面ガラス（板厚 4.0 mm フロートガラスまたは散乱光 AR コーティング強化ガラス）は、① 外部風速 v_wind [m · s⁻¹] による外部対流熱伝達率 h_out の増大、② 晴天夜間における天頂大気温度（Effective Sky Temperature: T_sky ≈ T_out − 12 〜 20 K）への長波長赤外線放射損失（波長 8 〜 14 µm）、および ③ 室内暖房管の対流循環による内部熱伝達率 h_in の変化を強く受けます。実効熱貫流率 U' [W · m⁻² · K⁻¹] は以下の複合抵抗モデルで表されます：

1 / U' = ( 1 / h_in ) + ( d_glass / λ_glass ) + ( 1 / ( h_out,conv(v_wind) + h_out,rad(ε_ir, T_sky) ) )
風速補正近似式 (ASABE / Kittas): U'(v_wind) ≈ U'_0 + b_w · ( v_wind )^0.8   （単層 4 mm ガラス設計基準値 U' ≈ 6.2 〜 6.8 W · m⁻² · K⁻¹）

特に伝統的なパテ無し重ねガラス（Lapped Glazing）や経年劣化したゴムガスケット構造では、温室内外の温度差 ΔT = 25 〜 30 K によって生じる浮力差（煙突効果 / Stack Effect: ΔP_stack = Δρ · g · H）により、屋根棟部から暖気が流出し側窓下部から冷気が流入する隙間換気回数 N_ach が 0.8 〜 1.5 h⁻¹ に達します。これに対し、現代の気密型アルミ形材・EPDM トリプルリップガスケットを備えた最新フェンロー温室（軒高 6.0 〜 7.0 m）では N_ach = 0.15 〜 0.35 h⁻¹ まで低減され、隙間換気損失だけで 15 〜 25 % の暖房燃料削減が達成されます。

3. 多層保温カーテン (Double / Triple Thermal Screens) の直列熱抵抗とアルミ蒸着放射遮蔽

ガラス被覆自体の二重化は通年の日積算光量（DLI: mol · m⁻² · d⁻¹）を恒久的に低下させ、「光量 1 % 減少 ＝ 収量 0.7 〜 1.0 % 減少」の収量ペナルティを招きます。そのためオランダ・ドイツ・日本の先進施設園芸では、日中は完全に収納して光透過率を最大化し、夜間および厳寒時のみ展開する多層水平保温カーテン（Multi-Layer Movable Thermal Screens：例 Svensson Luxous 1147 FR + Obscura / Harmony シリーズ）が標準設計となっています。

保温カーテンを n 層展開した際の実効熱貫流率 U'_screened は、カーテン上部の屋根裏空間（Attic Airspace）の対流抑制による静止空気層熱抵抗 R_airspace [m² · K · W⁻¹] と、カーテン繊維（透明ポリエステルストリップまたはアルミニウム蒸着ストリップ）による長波長放射遮蔽抵抗 R_screen,k の直列和として算出されます：

U'_screened [W · m⁻² · K⁻¹] = 1 / [ ( 1 / U'_unscreened ) + Σ R_screen,k + Σ R_airspace,k ]
カーテン省エネ率 η_screen = 1 − ( U'_screened / U'_unscreened )   （単層透明スクリーン: 43 〜 47 %、二重スクリーン: 62 〜 68 %）

また冬季の日の出直後に上層カーテンを急激に全開すると、屋根裏に溜まった 2 〜 5 ℃ の極低温空気塊（Cold AirAvalanche / 冷気塊落下）が一気に作物生長点（Apical Meristem）へ落下し、葉温の急低下による気孔閉鎖・結露発生（灰色かび病 Botrytis cinerea の胞子発芽リスク）および温湯暖房ボイラーの急激なオーバーシュートを引き起こします。これを防ぐため、環境制御コンピュータ（Priva Connext / Ridder Synopta / 誠和 プロファインダー）では、日の出前 45 〜 60 分 をかけて 2 % → 5 % → 10 % → 100 % と段階的に隙間を開ける段階的ギャップ開放制御（Stepwise Screen Gapping & Cold-Air Mixing）を実行します。

4. 潜熱回収ヒートポンプ・温湯蓄熱バッファタンクとバイバレント暖房設計 (Bivalent Sizing)

多層カーテンによって温室の気密性と断熱性を高めると、夜間の作物蒸散（15 〜 35 g · m⁻² · h⁻¹）によって室内の相対湿度が 88 〜 95 % RH に達し、除湿のために天窓を少し開けて暖房を焚く「焚き捨て除湿（Heating-with-Ventilation）」を行うと、せっかくのカーテン断熱効果が大きく損なわれます。これを根本的に解決するのが、空調除湿ユニット一体型・潜熱回収ヒートポンプ（Latent Heat Recovery Heat Pump / Mechanical Dehumidification ATU）です。

蒸散によって空気中に放出された水蒸気 1.0 kg は、約 2,450 kJ（≈ 0.68 kWh） の蒸発潜熱（Latent Heat of Vaporization h_fg）を保持しています。冷却コイルで露点温度以下に冷却して結露水を凝縮回収し、その凝縮潜熱と顕熱をヒートポンプ（成績係数 COP = 4.2 〜 5.2）で昇温して温湯暖房管（Rail-Pipe / Grow-Pipe）へ戻すことで、窓を一切開けずに除湿と暖房を同時に完結させることができます。

回収潜熱パワー Q_latent [kW · ha⁻¹] = 夜間蒸散量 m_trans [kg · h⁻¹ · ha⁻¹] × 蒸発潜熱 h_fg [2,450 kJ · kg⁻¹] / 3,600
バイバレント最適設計比率： ヒートポンプ定格出力 = ピーク暖房負荷 Q_max の 35 〜 45 % （年間暖房熱量の 78 〜 86 % をカバー）

さらに年間暖房負荷持続曲線（Annual Heating Load Duration Curve）を解析すると、設計最低外気温（T_out,design）が発生するのは年間 8,760 時間 のうちわずか 50 〜 120 時間 に過ぎません。したがって、ピーク負荷 100 %（例：120 〜 150 W/m²）をすべて高価なヒートポンプで賄うのではなく、ピーク負荷の 35 〜 45 %（45 〜 65 W/m²）を高効率ヒートポンプ（ベースロード機）で設計し、残りの極寒ピーク時のみ高効率エコジョーズ凝縮ボイラー（またはバイオマス・CHP）と 150 〜 250 m³/ha の温湯蓄熱バッファタンク（Thermal Stratification Buffer Tank）で補完するバイバレント（二元熱源）システムが、設備投資回収期間（Simple Payback: 3.2 〜 4.8 年）および生涯正味現在価値（NPV）を最大化するゴールデンスタンダードとなります。

施設園芸エンジニアリング 実践FAQ

Q1: DIN V 18599 および施設園芸設計基準に基づく温室ピーク暖房負荷 (kW・W/m²) の正確な計算式は？
ピーク暖房負荷 Q_tot [W] = [ U'_glazing × A_cov × (1 − η_screen) + 0.34 × V_house × N_ach ] × (T_in − T_out,design) で算出されます。例えば床面積 10,000 m² (1 ha)・外皮面積 12,200 m²・設定室温 18 ℃・外気設計温度 −7 ℃ (ΔT = 25 K) のフェンロー温室において、二重保温カーテン (η_screen = 0.64, U'_eff = 2.3 W/m²K) と高気密構造 (N_ach = 0.25 h⁻¹) を採用した場合、ピーク暖房負荷は無カーテン時の約 2,150 kW (215 W/m²) から約 815 kW (81.5 W/m²) へと 62 % 削減されます。

Q2: 保温カーテンを二重化（透明省エネ層＋アルミ反射層）すると日積算光量 (DLI) は低下しませんか？
最新のスリット折り畳み機構（ワイヤー駆動システム）と高透明スリットフィルム（Svensson Luxous 1147 FR 等）を使用した場合、日中収納時の束幅（バンドルサイズ）はスパンあたりわずか 40〜60 mm に収まり、日中の光量ロスは 1.5〜2.0 % 未満に抑えられます。一方、厳寒期の朝夕や夜間の熱損失は 62〜67 % 削減され、ガラス屋根面の放射冷却を防ぐことで上位葉の葉温が +1.5〜2.2 ℃ 高く保たれ、結果として光合成活性と果実肥大が向上します。

Q3: 温室用ハイブリッドヒートポンプと蓄熱バッファタンクの最適容量比率（バイバレント設計）は？
年間暖房負荷持続曲線の解析上、冬季ピーク暖房負荷の 35〜45 %（例：45〜60 W/m²）を高効率ヒートポンプ（COP 4.2〜5.0）でカバーする設計を行えば、年間の総暖房熱量（kWh/年）の 78〜86 % をヒートポンプのみで供給可能です。残りの年数回しか発生しない極寒夜間のピーク負荷（14〜22 % の熱量）を既存の凝縮ガス/重油ボイラーと温湯蓄熱タンク（150〜250 m³/ha）で補完するバイバレント構成が、初期投資（CAPEX）を半減させ最短の投資回収（ROI）を実現します。
