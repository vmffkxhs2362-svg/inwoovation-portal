1. C3 園芸作物のガス交換ジレンマと直列拡散抵抗ネットワーク（Ca → Cs → Ci → Cc）

フェンロー型連棟温室（太陽光利用型植物工場）および完全人工光型植物工場（PFAL）において栽培される主要園芸作物（トマト、パプリカ、キュウリ、イチゴ、リーフレタス等）はすべて C3 光合成経路を持つ高等植物です。陸上植物の葉の表皮は疎水性のクチクラワックス層で覆われており、大気中の二酸化炭素（CO2）を葉肉細胞の葉緑体ストロマへ取り込むためには、一対の孔辺細胞（Guard Cells）が形成する気孔（Stomata）を開口しなければなりません。しかし、気孔間隙の内部は相対湿度ほぼ 100%（水蒸気飽和状態）に保たれているため、CO2 流入のために気孔を開くと同時に、駆動ポテンシャル差（飽差）が数十倍大きい水蒸気が大気中へと大量に逸散します。通常、C3 作物が CO2 分子を 1 mol 固定する間に、実に 200〜500 mol もの水分子が蒸散によって失われる（蒸散比 Transpiration Ratio）という宿命的な熱力学・物質移動上のトレードオフが存在します。

生物環境工学（矢吹万寿による葉面境界層研究、千葉大学・農研機構および農業施設学会における群落ガス交換体系）では、施設内バルク空気（CO2 モル分率 Ca）から葉緑体ストロマ内の RuBisCO 活性部位（Cc）に至る CO2 輸送経路を、電気回路のオームの法則と等価な直列拡散抵抗網（または逆数であるコンダクタンス直列合成系）として定式化します。ここで重要な物理定数は、空気中における水蒸気（分子量 18.015 g · mol⁻¹、25 °C における二成分拡散係数 DH2O ≈ 2.42 × 10⁻⁵ m² · s⁻¹）と CO2（分子量 44.01 g · mol⁻¹、DCO2 ≈ 1.51 × 10⁻⁵ m² · s⁻¹）の分子拡散速度差です。

水蒸気蒸散フラックス： E = gtw · (wi − wa) ≈ gtw · (VPDleaf / Patm)   [mol H2O · m−2 · s−1]
水蒸気全コンダクタンス： 1 / gtw = 1 / gbw + 1 / gsw   （rtw = rbw + rsw）
境界層・気孔における拡散換算比： gbc = gbw / 1.37 ,   gsc = gsw / 1.60
CO2 全気相コンダクタンス： 1 / gtc = 1.37 / gbw + 1.60 / gsw
Fick の第一法則による純同化速度： An = gtc · (Ca − Ci) = gm · (Ci − Cc)   [µmol CO2 · m−2 · s−1]
ストロマ有効 CO2 モル分率： Cc = Ca − An · (1.37 / gbw + 1.60 / gsw + 1 / gm)

なぜ気孔内部では換算係数が 1.60 なのに対し、葉面境界層では 1.37 になるのでしょうか。気孔孔隙（孔径数 µm〜十数 µm）の内部では空気は完全に静止しており、純粋な分子拡散（Fick の法則）に従うため DH2O / DCO2 = 1.60 がそのまま適用されます。これに対し、葉の表面を覆う葉面境界層（Leaf Boundary Layer）では粘性流体の層流強制対流物質移動が支配的であり、シャーウッド数 Sh がシュミット数 Sc = ν / D の 1/3 乗に比例する境界層相似則（gb ∝ D2/3）から、(1.60)2/3 ≈ 1.37 が導出されます。さらに気孔下腔（Ci）に到達した CO2 は、細胞壁の水相へ溶解し、原形質膜（CO2 透過性アクアポリン PIP 群）、細胞質ゾル、炭酸脱水酵素（Carbonic Anhydrase）平衡、および葉緑体包膜を通過してストロマ（Cc）へ達します。この液相・膜透過コンダクタンスが葉肉コンダクタンス（gm：施設トマト・キュウリで概ね 0.15〜0.35 mol · m⁻² · s⁻¹ · bar⁻¹）であり、低温ストレスや塩類ストレス（高 EC 根圏）下では gs だけでなく gm の低下も光合成律速の主要因となります。

実務単位換算（モル単位系 vs 速度単位系）： ポータブル光合成蒸散測定装置（LI-6800 等）や植物生理学モデルではモルフラックス単位 g_sw [mol · m⁻² · s⁻¹]（または mmol · m⁻² · s⁻¹）を用いますが、温室空調・Penman-Monteith 蒸発散式では拡散抵抗 r_sw [s · m⁻¹] が汎用されます。理想気体の状態方程式（25 °C、101.325 kPa において空気モル体積 V_m ≈ 0.02447 m³ · mol⁻¹、モル密度 ρ_mol ≈ 40.87 mol · m⁻³）より、g_sw [mol · m⁻² · s⁻¹] ≈ 40.9 / r_sw [s · m⁻¹] と相互換算できます。例えば盛んに光合成するトマト上位葉の g_sw = 0.40 mol · m⁻² · s⁻¹ (400 mmol · m⁻² · s⁻¹) は r_sw ≈ 102 s · m⁻¹ に相当します。

2. Farquhar-von Caemmerer-Berry（FvCB）生化学モデルと Ball-Berry-Leuning（BBL）・Medlyn 最適気孔モデルの連成解法

施設園芸のデジタルツインおよびモデル予測制御（MPC）において、群落の CO2 吸収速度 An と蒸散速度 E を環境変数（PPFD、Tleaf、Ca、VPD、風速 u）から決定論的に予測するためには、生化学的需要式（FvCB モデル）と気孔拡散供給式（BBL または Medlyn モデル）を連立させて自己無撞着に解く必要があります。Farquhar, von Caemmerer & Berry (1980) ならびに Sharkey (1985) によれば、C3 葉の純 CO2 同化速度 An は以下の3つの生化学プロセスの最小律速速度からミトコンドリア明呼吸速度 Rd を差し引いた値で与えられます。

FvCB 生化学3律速モデル： An = min( Wc , Wj , Wp ) · (1 − Γ* / Ci) − Rd   （厳密形では Cc 基準）
(1) Rubisco カルボキシラーゼ律速速度： Wc = [ Vcmax · Ci ] / [ Ci + Kc · (1 + O / Ko) ]
(2) RuBP 再生（電子伝達 J）律速速度： Wj = [ J(PPFD) · Ci ] / [ 4 · Ci + 8 · Γ* ]
非直角双曲線電子伝達速度： θ · J2 − (αleaf · ΦPSII,max · PPFD + Jmax) · J + αleaf · ΦPSII,max · PPFD · Jmax = 0
(3) トリオースリン酸利用（TPU）律速： Wp = 3 · Tp · Ci / (Ci − Γ*)

ここで Vcmax は最大 Rubisco カルボキシラーゼ活性（トマト成葉 25 °C 基準で 75〜115 µmol · m⁻² · s⁻¹）、Jmax は最大線形電子伝達速度（概ね Jmax / Vcmax ≈ 1.65〜2.0）、Kc（≈ 404.9 µmol · mol⁻¹）および Ko（≈ 278.4 mmol · mol⁻¹）はそれぞれ CO2 と O2（O = 210 mmol · mol⁻¹）に対するミカエリス定数、Γ*（25 °C で ≈ 42.75 µmol · mol⁻¹）は光呼吸による CO2 放出とカルボキシラーゼ固定が均衡する葉緑体 CO2 補償点です。これらの生化学パラメータはすべて Arrhenius 式（または高温失活項を含む Peaked Arrhenius 関数）に従い葉温 Tleaf の非線形関数として変化します。

一方、孔辺細胞が環境と葉内同化状態に応じて気孔コンダクタンス gsw をどのように調節するかを記述する半経験・理論モデルとして、以下の3世代の定式化が国際標準として確立されています。

[第1世代] Ball-Woodrow-Berry (BWB, 1987) 式：
  gsw = g0 + m · (An · hs) / Cs
[第2世代] Ball-Berry-Leuning (BBL, Leuning 1995) 式：
  gsw = g0 + [ a1 · An ] / [ (Cs − Γ*) · (1 + Ds / D0) ]
[第3世代] Medlyn 統一最適気孔モデル (Medlyn et al., 2011)：
  gsw = g0 + 1.60 · ( 1 + g1 / √Ds ) · ( An / Cs )
  • 残余（クチクラ・不完全閉鎖）コンダクタンス g0： 暗期または An → 0 における最小コンダクタンス（健全な温室作物で 0.008〜0.025 mol · m⁻² · s⁻¹）。ただし長期間の高湿度（VPD < 0.35 kPa）で育った軟弱徒長葉では気孔の閉鎖不全（Stomatal Malfunctioning）が生じ、g0 が 0.06 mol · m⁻² · s⁻¹ 以上に跳ね上がって晴天急変時に激しい萎凋を引き起こします。
  • BWB から BBL への進化理由： 初期の Ball-Woodrow-Berry 式は葉面相対湿度 hs（0〜1）を用いたため、異なる葉温で同じ相対湿度であっても飽差 Ds が倍増する物理効果を区別できませんでした。Leuning (1995) の BBL モデルは葉面飽差 Ds [kPa] と基準飽差感度パラメータ D0（C3 果菜類で 1.2〜1.6 kPa）による双曲線減衰項 1 / (1 + D_s / D_0) を導入し、さらに分母を C_s − Γ* とすることで低 CO2 光補償点近傍での整合性を確立しました（スロープ係数 a1 ≈ 9.0〜12.5）。
  • Medlyn 最適気孔理論（Cowan & Farquhar 1977 の解析解）： 植物が一定期間の利用可能水量を制約条件として炭素獲得総量を最大化する変分問題 ∂A_n / ∂E = λ = const.（限界水利用効率一定則）を RuBP 再生律速下で解析的に解くと、1 + g_1 / √D_s という飽差の平方根逆数依存性が厳密に導かれます。ここで g1 [kPa0.5] は限界水コスト √λ に比例する単一パラメータであり、乾燥耐性作物では小さく（g_1 ≈ 2.0〜3.0）、潤沢に灌水される施設水耕トマト・キュウリ・レタスでは大きな値（g_1 ≈ 4.2〜5.8 kPa^0.5）を示します。

数値シミュレーション上の実装では、未知数ベクトル X = [A_n, g_sw, C_i, T_leaf] が互いに循環参照しています（Tleaf が飽差 Ds と酵素速度 Vcmax, Jmax を決め、それが An を決め、An が gsw を決め、gsw が蒸散冷却 λE を通じて再び Tleaf を更新する）。高精度シミュレーターでは、(1) 外側ループで葉面熱収支式から Tleaf を収束させ、(2) 内側ループで FvCB の二次方程式と BBL 式から得られる Ci の三次代数方程式（または緩和係数 ω = 0.5 の減衰固定点反復・Brent 法）を |ΔC_i| < 0.05 µmol · mol⁻¹ まで 5〜12 回反復して厳密解を求めます。

3. 葉面境界層抵抗（rb）の流体力学：レイノルズ数・シャーウッド数・デカップリング係数（Ω）と循環気流設計

どれほど気孔が大きく開口していても（高い gsw、低い rsw）、葉の表面に厚い静止空気の膜（葉面境界層：Leaf Boundary Layer）が張り付いていれば、大気から気孔入口への CO2 供給と気孔からの水蒸気・顕熱放散はすべて境界層抵抗 rb によって頭打ちになります。流体力学の平板層流境界層理論（Blasius 解および Pohlhausen 物質移動相関）によれば、風速 u [m · s−1]、気流方向の代表葉長 dleaf [m]（葉幅に約 0.72 を乗じた特性長）における境界層厚さ δbl と水蒸気境界層抵抗 rbw は次式で支配されます。

葉面レイノルズ数： Re = (u · dleaf) / νair   （25 °C 空気動粘性係数 νair ≈ 1.56 × 10−5 m2 · s−1）
層流強制対流シャーウッド数： Sh = 0.664 · Re1/2 · Sc1/3 · βturb   （屋外・循環扇乱流増強係数 βturb ≈ 1.25〜1.50）
境界層厚さスケーリング： δbl ≈ 4.0 · √( dleaf / u )   [mm]   （dleaf [m], u [m · s−1]）
水蒸気境界層抵抗の実用工学式： rbw ≈ 180 · √( dleaf / u )   [s · m−1]   ⇒   gbw ≈ 0.227 · √( u / dleaf )   [mol · m−2 · s−1]
Jarvis-McNaughton 結合係数（Decoupling Factor）： Ω = (Δ / γ + 1) / (Δ / γ + 1 + gbw / gsw)   （0 ≤ Ω ≤ 1）

この平方根則 r_bw ∝ √(d_leaf / u) は、施設園芸の気流設計において極めて重要な3つの定量的帰結をもたらします。

  1. 葉サイズ効果（キュウリ大葉 vs トマト複葉）： 小葉に分かれたミニトマト（dleaf ≈ 0.04 m）に比べ、大葉のキュウリやメロン（dleaf ≈ 0.20〜0.25 m）は同じ風速下でも境界層抵抗 rbw が 2.2〜2.5倍 大きくなります。したがって大葉作物群落ほど高い気流速度が要求されます。
  2. 無風デッドゾーンの非線形ペナルティ： 冬季の密閉温室で循環扇を停止し群落内風速が u = 0.05 m · s⁻¹ まで低下すると、dleaf = 0.12 m の葉で r_bw ≈ 279 s · m⁻¹（CO2 換算で r_bc = 1.37 × 279 ≈ 382 s · m⁻¹）に達し、開いた気孔自身の抵抗（r_sw ≈ 110 s · m⁻¹）の2.5倍以上のボトルネックとなります。このとき室内通路の CO2 濃度が 900 ppm でも葉面 Cs は 560 ppm 前後まで低下し、高価な液化 CO2 施用コストの大半が無駄になります。
  3. デカップリング係数 Ω と微気象乖離： Jarvis & McNaughton (1986) のデカップリング係数 Ω が 1 に近い（風速が低く葉が大きく gbw / gsw が小さい）温室群落では、蒸散は室内 VPD よりも正味放射 Rn に強く支配され、強日射下で葉温が室温より +3.0〜+4.5 K 急上昇します。水平循環扇（HAF ファン）または株元ダクト送風により群落内風速を u = 0.30〜0.60 m · s⁻¹ の最適帯へ引き上げると、r_bw は 80〜115 s · m⁻¹ まで急減し、葉温と気温の乖離が ±1.0 K 以内に収束して純光合成速度 An が +18〜+32% 向上します。なお、u > 1.0〜1.2 m · s⁻¹ の過度な強風は葉の機械的揺動と過蒸散による気孔閉鎖を招くため逆効果となります。

4. 飽差（VPD）ストレス応答と気孔開閉カイネティクス：昼寝現象（Midday Depression）・ABA シグナル・変動光追従遅れ

温室の環境制御盤が表示する「室内気温・室内相対湿度から計算した空気飽差（VPDair）」ではなく、孔辺細胞が実際に晒されている熱力学的駆動力は葉温 Tleaf 基準の葉面飽差（Leaf-to-Air VPD: VPDleaf）です。Tetens-Magnus 式による飽和蒸気圧 esat(T) を用いると、VPDleaf は次式で厳密に定義されます。

飽和蒸気圧 (Tetens 式)： esat(T) = 0.61078 · exp[ (17.2694 · T) / (T + 237.29) ]   [kPa]   （T [°C]）
実効葉面飽差： VPDleaf = esat(Tleaf) − eair = esat(Tleaf) − (RHair / 100) · esat(Tair)   [kPa]
水ポテンシャル連続式（SPAC）： Ψleaf = Ψroot − ρw · g · hc − E · Rhyd,plant   [MPa]

例えば室温 T_air = 25.0 °C、相対湿度 RH_air = 65% のとき、空気飽差は VPD_air = 3.168 × (1 − 0.65) = 1.11 kPa と一見適正に見えます。しかし強日射下で気流が弱く葉温が T_leaf = 28.5 °C（e_sat = 3.891 kPa）まで上昇していると、実際の葉面飽差は VPD_leaf = 3.891 − 2.059 = 1.83 kPa に達し、作物は深刻な高飽差乾燥ストレス下に置かれます。気孔の VPD 応答は、以下の3つのレジームと時間スケールで進行します。

  • 過湿・低飽差レジーム（VPDleaf < 0.45 kPa）： 蒸散駆動力が失われ、木部道管（Xylem）のマスフローに完全依存して輸送される非移動性養分——とりわけ細胞壁ペクチン架橋に不可欠なカルシウムイオン（Ca2+）とホウ素（B）——の成長点・果実先端への供給が途絶し、トマト・パプリカの尻腐れ症（Blossom-End Rot: BER）やレタス・イチゴのチップバーン（縁腐れ症）を誘発します。さらに葉面境界層で局所結露が生じ、灰色かび病（Botrytis cinerea）やべと病の分生子発芽条件を満たしてしまいます。
  • 最適光合成・蒸散協調バンド（VPDleaf = 0.75 〜 1.20 kPa）： 育苗・活着期は 0.60〜0.85 kPa、栄養成長〜生殖成長盛期は 0.85〜1.20 kPa において、孔辺細胞の高い膨圧が維持されて気孔コンダクタンス gsw が極大化し、Ci / Ca 比が 0.72〜0.82 の高水準に保たれます。
  • 高飽差ストレス・昼寝現象（Midday Stomatal Closure, VPDleaf > 1.45 〜 1.60 kPa）： 蒸散要求量 E が根系・茎木部の水理コンダクタンス供給能力（Kplant = 1 / Rhyd,plant）を上回ると、葉水ポテンシャル Ψleaf が臨界値（トマトで −0.9〜−1.2 MPa）を下回ります。最初は表皮・孔辺細胞からの直接脱水によるハイドロパッシブ反応（一時的な逆接開口 Wrong-Way Response を経た急閉鎖）が起こり、続いて葉肉および維管束柔細胞で生合成・脱抱合された植物ホルモンアブシジン酸（ABA）が孔辺細胞の PYR/PYL/RCAR 受容体 → OST1 (SnRK2.6) キナーゼ → S型アニオンチャネル SLAC1 を活性化します。Cl− とリンゴ酸イオンの流出に伴う膜脱分極が外向き整流性 K+ チャネル（GORK）を開き、浸透圧低下に伴う水流出によって気孔が強力に閉鎖されます（ハイドロアクティブ閉鎖）。一度 ABA 誘導性の閉鎖が起きると、午後に日射が緩み VPD が回復しても気孔開度の回復には 45〜90分 の強いヒステリシス（履歴遅れ）が残り、1日の積算同化量が 15〜30% 失われます。
  • 動的変動光に対する気孔の時定数遅れと青色光プライミング： 太陽光利用型温室で雲の通過により PPFD が 150 → 900 µmol · m⁻² · s⁻¹ へステップ状に急増した際、チラコイド電子伝達は数ミリ秒、Rubisco activase による生化学誘導は 1〜3分 で立ち上がるのに対し、イオン輸送と水流入を伴う気孔開口の時定数 τopen は 8〜20分 を要します（Vialet-Chabrand et al., 2017）。この開口遅れ期間中は Ci が急落して CO2 供給律速が生じます。最新のハイブリッド LED 補光戦略では、早朝日の出前や曇天変動時に低強度（25〜40 µmol · m⁻² · s⁻¹）の450 nm 青色 LED 光を照射し、孔辺細胞特異的な青色光受容体フォトトロピン（PHOT1 / PHOT2）→ 細胞膜 H⁺-ATPase リン酸化活性化を介して気孔をあらかじめ予備開口（Stomatal Priming）させておくことで、直後の自然光スパイクを逃さず同化へと変換します。

💧 リアルタイム葉面飽差（VPDleaf）＆気孔蒸散ストレス・インタラクティブ計算機

施設内気温・相対湿度・放射葉温オフセット（ΔT = Tleaf − Tair）をスライダーで操作し、実効葉面飽差（kPa）と気孔コンダクタンス活性帯をリアルタイムに検証できます。

5. 太陽光利用型植物工場・半閉鎖型温室における CO2 施用収支と統合環境制御アーキテクチャ

C3 作物の現在の外気 CO2 濃度（C_out ≈ 425 µmol · mol⁻¹）は Rubisco の CO2 飽和濃度を大きく下回っており、光合成と競合する光呼吸（Photorespiration：Rubisco による O2 固定反応）によってせっかく固定した炭素の 20〜30% が失われています。施設内 CO2 濃度 Ca を 800〜1,100 µmol · mol⁻¹ (ppm) に高めると、Ci が上昇して光呼吸が劇的に抑制され、純光合成速度 An は +22〜+38% 増加します。同時に BBL 式（g_sw ∝ A_n / (C_s − Γ*)）から明らかなように、分母の Cs 増大率が分子の An 増大率を上回るため、気孔コンダクタンス gsw は 15〜25% 緩やかに縮小し、固有水利用効率（Intrinsic Water Use Efficiency: iWUE = An / gsw）が 1.5〜1.8倍 に向上します。

ただし、春季〜秋季の日射が強い時間帯に天窓を全開にして換気を行う従来型温室では、施用した CO2 が毎時 15〜40回 の換気回数（Nvent）によって屋外へ流出し、高濃度維持の経済性が崩壊します。温室単位床面積あたりの CO2 動的物質収支と経済的最適設定値 Ca* は次式で記述されます。

温室 CO2 動的物質収支： hgh · ρair · (dCa / dt) = ΦCO2,inj − Φvent − Pcanopy,net(PPFD, Ca, Tleaf, VPDleaf)
換気流出フラックス： Φvent = Nvent · hgh · ρair · (Ca − Cout)   [g CO2 · m−2 · h−1]
群落アップスケーリング同化量（Sunlit / Shaded 二葉モデル）：
  Pcanopy,net = LAIsun · An(Isun, gs,sun) + LAIshd · An(Ishd, gs,shd)
経済的限界最適条件（MPC 目的関数）： ∂[ pcrop · HI · εbio · Pcanopy,net(Ca) ] / ∂Ca = pCO2 · ( ∂ΦCO2,inj / ∂Ca )

ここで hgh は温室平均軒高（現代のオランダ・日本型ハイワイヤー温室で 5.5〜6.8 m）、pcrop は収穫果実単価、HI は収穫指数（Harvest Index、トマトで 0.65〜0.72）、εbio は CO2 1 g から乾物・新鮮重への変換係数、pCO2 は液化炭酸ガスまたは CHP（コージェネレーション SCR 脱硝精製排ガス）の CO2 単位コストです。この連立問題に対する最先端の工学的解決策が、(1) 高圧細霧冷房（High-Pressure Fogging：粒径 5〜15 µm、圧力 7〜10 MPa）による蒸発冷却と VPD 維持（天窓開度を最小化して Nvent を抑えつつ VPD_leaf = 0.9〜1.1 kPa を死守）、および (2) 空調ユニット（ATU）やヒートポンプで顕熱・潜熱を回収し天窓を閉じたまま高 CO2（1,000 ppm）を終日維持する半閉鎖型温室（Semi-Closed Greenhouse）＋局所株間 CO2 チューブ施用です。

6. 施設園芸・植物工場エンジニアのための実務 FAQ（気孔・光合成ガス交換動力学）

Q1. 水蒸気に対する気孔コンダクタンス（gsw）と CO2 に対する気孔コンダクタンス（gsc）の換算比が 1.60 となり、葉面境界層では 1.37 となる物理的根拠は何ですか？

気孔孔隙内部のガス移動は静止空気中の純粋な分子拡散（Fick の第一法則）に支配されるため、水蒸気（分子量 18.015 g·mol⁻¹、拡散係数 約 2.42×10⁻⁵ m²·s⁻¹）と CO2（分子量 44.01 g·mol⁻¹、拡散係数 約 1.51×10⁻⁵ m²·s⁻¹）の空気中二成分拡散係数比 DH2O / DCO2 ≈ 1.60 がそのまま gsw / gsc = 1.60 の比率になります。一方、葉面境界層（rb）では層流強制対流物質移動が支配的となり、シャーウッド数 Sh ∝ Sc1/3 の境界層相似則から拡散係数比の 2/3 乗である (1.60)2/3 ≈ 1.37 が水蒸気境界層コンダクタンス gbw と CO2 境界層コンダクタンス gbc の換算係数となります。

Q2. 従来の Ball-Woodrow-Berry モデルに対し、Ball-Berry-Leuning（BBL）モデルや Medlyn モデルが施設園芸の環境制御において優れている点は何ですか？

初期の Ball-Woodrow-Berry (1987) モデルは葉面相対湿度 hs に比例する定式化であったため、気温変化時や高飽差環境下での孔辺細胞の水ポテンシャル応答を正確に分離できませんでした。Leuning (1995) の BBL モデルは相対湿度 hs を葉面飽差 Ds の双曲線減衰関数 1 / (1 + Ds / D0) に置換し、さらに CO2 補償点 Γ* を導入することで蒸散駆動力に対する生理的閉鎖応答を精密化しました。また Medlyn et al. (2011) の統一最適気孔モデルは限界水利用効率（∂A/∂E = 一定）の変分原理から 1 + g1 / √Ds の平方根依存性を導出し、パラメータ g1 に作物ごとの水利用戦略という明確な生物物理学的意味を与えています。

Q3. 無風状態の温室内で CO2 を 1,000 ppm に施用しても、期待した光合成促進効果が得られないのはなぜですか？

群落内風速 u が 0.08 m·s⁻¹ 未満の無風状態では、葉面境界層抵抗 rbw が 350〜500 s·m⁻¹ 以上に増大し、厚い静止空気の断熱・拡散バリアが形成されます。その結果、通路上の NDIR センサーが Ca = 1,000 ppm を示していても、活発に同化する葉面直上の CO2 濃度 Cs は 520〜600 ppm まで局所枯渇します。同時に蒸散潜熱放散が阻害されて葉温 Tleaf が気温より 3〜4 K 上昇し、実効葉面飽差 VPDleaf が 1.6 kPa を超えて気孔閉鎖を誘発するためです。HAF 循環扇等で群落風速 0.30〜0.55 m·s⁻¹ を確保し、rbw を 80〜130 s·m⁻¹ 以下へ低減することが不可欠です。

Q4. 高濃度 CO2 施用（800〜1,200 ppm）を行う際、温度や飽差（VPD）の設定値をどのように連動補正すべきですか？

外気 CO2 濃度の上昇に伴い細胞間隙 CO2 濃度 Ci が高まると、BBL 式に従い孔辺細胞は気孔コンダクタンス gsw を 15〜25% 縮小させて水分損失を節約します。この部分的な気孔閉鎖により蒸散冷却フラックス（λ·E）が減少し、強光下では葉温が 0.6〜1.2 K 上昇します。同時に Rubisco の酸素化反応（光呼吸）が抑制されるため、純光合成速度 An の最適葉温自体が通常の 22〜24 °C から 26〜29 °C へと高温側へシフトします。したがって高 CO2 施用時は換気開始温度を +2〜3 K 引き上げつつ、VPDleaf が 0.85〜1.15 kPa の適正帯を逸脱しないよう細霧冷房や循環気流を協調制御する必要があります。
