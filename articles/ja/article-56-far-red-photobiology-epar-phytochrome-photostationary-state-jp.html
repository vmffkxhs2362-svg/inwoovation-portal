1. PAR (400–700 nm) から ePAR (400–750 nm) への光生物学パラダイム転換

半世紀以上にわたり、施設園芸および植物工場の補光設計は McCree (1972) の古典的 PAR (光合成有効放射, 400–700 nm) 定義を絶対基準としてきた。この枠組みでは波長 700 nm を超える遠赤色光 (Far-Red, 700–750 nm) は単独照射時の量子収率が急落するため光合成に寄与しない「非光合成帯域」と見なされ、従来の量子光センサーでも計測対象から除外されていた。

しかし、ユタ州立大学の Zhen & Bugbee (2020) およびオランダ・ワーゲニンゲン大学 (WUR) の一連の精密光量子実験により、太陽光や多波長 LED 補光下では 700–750 nm の遠赤色光子が短波長光 (400–700 nm) と同等の量子収率で炭酸固定を駆動することが実証され、拡張光合成有効放射 (Extended PAR, ePAR: 400–750 nm) が国際標準へと定着しつつある。

その物理的機構は葉緑体チラコイド膜に直列配置された 2 つの光化学系の協調動作にある。狭帯域の赤色 (660 nm) と青色 (450 nm) のみで葉を照射すると、光化学系 II (PSII, 励起極大 ≈ 680 nm) が過剰励起される一方で、長波長域に吸収帯を持つ 光化学系 I (PSI, 励起極大 ≈ 700–730 nm) が律速段階となり、プラストキノン (PQ) プールで電子輸送渋滞が発生する。ここに 700–750 nm の遠赤色光子を加えると PSI が選択的に励起されて PQ プールが解放され、線形電子伝達および ATP/NADPH 供給が劇的に回復する。この相乗効果は エマーソン増強比 (Emerson Enhancement Ratio, EER) として次式で定量化される。

EER = Acombined(λ400–700 + λ700–750) / [ APAR(λ400–700) + AFR(λ700–750) ] > 1.0

高軒高トマト (Solanum lycopersicum) やパプリカ (Capsicum annuum)、イチゴにおいて、赤青ベースライン光に対して 10 % – 20 % の遠赤色光子 (PFDFR) を重畳すると、同じ光量子数を純粋な 660 nm 赤色光で増設した場合と同等以上の純光合成速度 A [ μmol CO2·m-2·s-1 ] が得られる。結果として、オランダ・ウェストラントや日本・静岡/千葉の大型太陽光利用型植物工場では「赤+青+遠赤」の ePAR スペクトル設計が主力へと移行している。

2. フィトクロム光平衡状態 (PSS) の数理定式化とスペクトル制御

遠赤色光は光化学系の駆動と同時に、植物の形態形成を司る光受容体 フィトクロム (Phytochrome) を直接制御する。フィトクロムは赤色光を吸収する不活性型 Pr (吸収極大 660 nm) と、遠赤色光を吸収して戻る生物学的活性型 Pfr (吸収極大 730 nm) の 2 状態間を可逆的に光変換する分子スイッチである。

任意の分光放射光量子束密度スペクトル N(λ) [ μmol·m-2·s-1·nm-1 ] 下における定常状態での活性型割合を フィトクロム光平衡状態 (Phytochrome Photostationary State, PSS) と定義し、Sager et al. (1988) の光化学反応断面積 σr(λ), σfr(λ) を用いて以下の積分で厳密計算される。

PSS = [Pfr] / [Ptotal] = ∫300800 λ · N(λ) · σr(λ) dλ / [ ∫300800 λ · N(λ) · σr(λ) dλ + ∫300800 λ · N(λ) · σfr(λ) dλ ]
  • 太陽光 (自然光, R:FR ≈ 1.15–1.25) : 基準となる PSS ≈ 0.70–0.72 を確立し、過度な徒長と矮化の中間にある調和した草姿を保つ。
  • 狭帯域 R+B LED (R:FR > 8.0) : 730 nm 成分が欠如するため PSS ≈ 0.84–0.88 まで上昇し、節間が極度に詰まったコンパクトな草姿・厚葉化（高 SLW）を示す。
  • 群落内日陰光 (R:FR < 0.20) : 上位葉が 400–700 nm を 90 % 以上吸収する一方、遠赤色光の 80 % 以上が透過するため PSS ≈ 0.45–0.55 へ急落し、典型的な 避陰反応 (Shade Avoidance Syndrome, SAS) を誘発する。

3. PSS ターゲット領域別の形態反応と施設園芸作物別ドーシング設計

化学的矮化剤（植物成長調整剤）を使用せず、LED チャンネル調光のみで PSS を操作することで、育苗期の徒長防止から冬期の受光面積拡大まで自在に草姿をステアリングできる。

4. 昼間連続 ePAR 添加と日没後 EOD-FR パルス照射の工学的比較

商業施設において 730 nm 遠赤色 LED を運用する際、エンジニアリング上は大きく 2 つの制御アルゴリズムに大別される。

  1. 戦略 A：昼間連続 ePAR 補光 (Continuous Daytime Far-Red) : 主照明（広帯域白色または赤青 LED）の点灯時間全体を通じて総光量子束の 10–15 % の遠赤色光を同時照射する方式。終日エマーソン増強効果（純炭素固定量 +8 % – +12 %）を享受できるうえ、PSS ≈ 0.65 前後を維持して葉面積を拡大し、温室全体の DLI (日積算光量) 捕捉率を底上げする。長段取りトマトの増収に直結する標準戦略である。
  2. 戦略 B：日没後 EOD-FR パルス照射 (End-of-Day Far-Red Pulse) : 日中の強い補光時に連続照射すると茎長が伸びすぎて誘引作業負荷や倒伏リスクが増す場合、主照明消灯直後に 15–30 分間、20–40 μmol·m-2·s-1 の遠赤色パルスのみを照射する。これにより夜間開始前にフィトクロムを速やかに不活性型 Pr (PSS < 0.40) へ反転させ、果実への乾物分配率（Brix 糖度）を損なうことなく葉展開と花梗・葉柄伸長だけを安価な電力投入で引き出せる。

また日本の夏季・中間期の温暖地（太平洋側ハウス）では、遠赤色光を単独の補助モジュールとして分離し、外気温と日射積算に応じて 0–10 V / DALI-2 調光で PSS を季節可変させる設計が冷房負荷と過徒長の両方を抑える最適解となる。

5. 730 nm 素子の電気光学効率、温熱収支および国際補助金連携

半導体発光物理の観点では、AlGaAs 系 730 nm 遠赤色 LED チップはバンドギャップエネルギー（約 1.70 eV）が青色（450 nm, 約 2.75 eV）や蛍光体変換白色 LED より大幅に小さいため、壁コンセント効率 (WPE, ηopt) が 70–75 % に達し、照明器具レベルの光量子効率 (PPE) は 3.8 – 4.2 μmol/J と極めて高い。

Δ Hcanopy = ∫ [ (1 - αPAR) · PPFD + (1 - αFR) · PFDFR ] dλ + Q̇convection

さらに高圧ナトリウムランプ (HPS) のような過剰な赤外熱放射を伴わないため、上位葉群の葉温過昇（VPD 急騰・気孔閉鎖）を招きにくい。補光設備総電力の 15 % を高効率 730 nm チャンネルへシフトすることで、同等の光化学駆動力を維持したまま 設備接続電力および補光電力消費を約 7.4 % 削減 でき、DLC Horticultural QPL 規格（PPE ≥ 2.8 μmol/J）や日本の農林水産省（MAFF）省エネ農業施設導入支援・米国 USDA REAP / CDFA SWEEP・ドイツ BLE 連邦エネルギー効率補助金の技術要件を同時に満たすことが可能である。

自社の目標 DLI と点灯時間から必要な 730 nm チャンネル比率と年間電力量を試算するには、当ラボの DLI・LED スペクトル統合計算機、DLI・光形態形成スペクトル計算機、PAR・遠赤色群落透過減衰計算機、および 世界 8 か国 192 農業補助金ナビゲーター を活用されたい。

施設園芸エンジニアリング 実践FAQ

Q1: なぜ遠赤色光 (700–750 nm) を含めた ePAR が古典的な PAR (400–700 nm) に取って代わったのですか？
従来の PAR は単独照射時の量子収率が低い 700–750 nm を除外していましたが、実際の太陽光や赤青 LED 下では PSI と PSII が直列稼働するため、700–750 nm の遠赤色光子が PSI を選択的に励起してエマーソン増強効果 (EER > 1.0) を発揮し、400–700 nm 光子と同等の高効率で光合成を促進することが Zhen & Bugbee (2020) により実証されたためです。

Q2: フィトクロム光平衡状態 (PSS) は何%の遠赤色比率でどのように管理すべきですか？
太陽光基準は PSS ≈ 0.70–0.72 です。徒長を抑えたい育苗・レタス生産では PSS 0.80–0.88（遠赤色ごく微量）、トマト・パプリカの本圃増収には PSS 0.68–0.74（総光量子の 8–12 % を 730 nm で配合）、冬季低日射期の早期葉面積拡大には PSS 0.55–0.65（15–20 % 配合）が標準目標となります。

Q3: 昼間連続照射と日没後 EOD パルス照射 (15–30 分) はどう使い分けますか？
果実肥大期のトマト等で純光合成速度そのものを +8–12 % 引き上げたい場合は昼間連続照射（ePAR 戦略）を採用し、日中の節間伸長を抑えつつイチゴの花房抽出やキュウリの葉展開だけを最小電力で促したい場合は消灯直後の 15–30 分 EOD パルス (20–40 μmol·m⁻²·s⁻¹) を適用します。

Q4: 730 nm 遠赤色 LED の導入は日米欧の省エネ補助金 (MAFF / BLE / USDA REAP) の対象になりますか？
はい。730 nm LED は器具効率 3.8–4.2 μmol/J と極めて高効率であるため、システム全体の PPE ≥ 2.8–3.0 μmol/J 要件および 0–10 V / DALI 調光制御要件を満たしやすく、ドイツ BLE、米国 USDA REAP / CDFA SWEEP、日本 MAFF 省エネ施設園芸支援のいずれでも有力な補助対象設備となります。
