Vol. 54: 商業用フェンロー温室における AI モデル予測制御 (MPC) とエネルギー・収量同時最適化

🌐 Vol. 54 Editions: 🇬🇧 English Edition → 🇩🇪 Deutsche Ausgabe → 🇯🇵 日本語版 (JA) (Active)
👨‍🔬 Inwoo Hwang (Inwoovation Lab)  |  📅 Last Updated: November 26, 2026  |  ⏱️ 14 min read · Model Predictive Control (MPC), DIN V 18599 & EPEX SPOT

1. 状態空間エネルギー収支 ODE と動的保温カーテン伝熱制御 (DIN V 18599)

オランダの Westland (ウェストラント)、ドイツの Niederrhein / Straelen (シュトラエレン) やバイエルン州ニュルンベルクの Knoblauchsland (クノーブラウフスラント)、さらに日本の大規模次世代施設園芸クラスターにおいて、環境制御パラダイムは歴史的な転換点を迎えている。従来のルールベース PID 気候制御コンピューター ( Priva Connext 、 Hoogendoorn iGro 等 ) は、静的な P-band (比例帯) と固定時刻設定値に依存した事後修正型制御であった。これに対し AI モデル予測制御 ( Model Predictive Control, MPC ) は、商業用フェンロー型連棟温室 ( Venlo Glasshouse ) を多入力多出力 ( MIMO ) の非定常熱力学システムとして状態空間モデル化し、24 – 48 時間の気象予報と時間別電力市場価格をリアルタイムに取り込んで純収益を最大化する。

温室内の非定常顕熱空気温度 Tin(t) は、熱力学第一法則に基づき、温水パイプ放熱 Q̇pipe(t) 、日射透過取得 ηrad · Isolar(t) · Afloor 、被覆屋根面からの貫流熱損失 Uoverall(t) · Aroof · (Tin - Tout) 、および天窓換気による顕熱交換によって決定される。特にアルミ蒸着保温カーテン ( Svensson Luxous + Obscura 等の 2 層スクリーン ) を展開すると、4 mm 単層フロートガラス基準の総合熱貫流率 Uoverall = 6.5 W/(m2·K) が 2.2 W/(m2·K) 以下へと劇的に低下し、夜間放熱負荷を約 66 % 抑制する。

Cair · V · (dTin / dt) = Q̇pipe(t) + ηrad · Isolar(t) · Afloor - Uoverall(t) · Aroof · (Tin - Tout) - ρair · cp · V̇vent(t) · (Tin - Tout)
  • Cair · V [ J / K ] : 施設内空気容積および構造・作物熱容量を含む有効熱容量。気象外乱ステップに対する時定数を規定する。
  • Uoverall(t) [ W / (m2·K) ] : 2 層保温カーテンの開閉度合 ( 0 – 100 % ) および風速に連動して時刻ごとに変動する動的熱貫流率。
  • V̇vent(t) [ m3 / s ] : 温室内外温度差による煙突効果 ( Stack Effect ) と風上・風下天窓開度から算出される自然換気風量。

2. 非定常水分収支・VPD 制御と日没 45 分前プリパージによる灰色かび病抑制

作物群落からの気孔蒸散 Etrans は、極めて巨大な潜熱ヒートシンクおよび水蒸気発生源として機能する。室内の絶対湿度 xin [ kgwater / kgair ] は、葉面積指数 ( LAI ) 、葉面飽差 ( VPDleaf ) 、および日射量 Isolar に依存する蒸散フラックスと、天窓換気による絶対湿度差排出の動的バランスで推移する。

ρair · V · (dxin / dt) = Etrans( LAI, VPDleaf, Isolar ) - ρair · V̇vent(t) · (xin - xout)

従来型の PID 制御では、相対湿度 ( RH ) が 85 % を超過して初めて天窓を事後開放するため、外気温が急落する夕暮れ時に高価な暖房熱量を一気に放出してしまう欠陥があった。これに対し AI-MPC は、太陽高度角・風速・外気露点温度予報から夜間の放射冷却と葉面結露リスクを先行予測し、日没 45 分前から段階的な制御換気に入りパージ ( Progressive Ventilation Purge ) を先行実行する。これにより、頂芽分裂組織 ( Apical Meristem ) への冷気下降ショックと果実マイクロクラッキングを完全に防ぎながら、生理的最適域である VPD = 0.8 – 1.2 kPa を安定維持し、灰色かび病 ( Botrytis cinerea ) の胞子発芽を物理的に遮断する。

3. 非線形多目的 MPC 目的関数 J と作物生理ハード制約条件

上位 MPC 最適化ソルバーは 5 分 ( Δt = 300 s ) 周期で、予測ホライズン Hp = 24 – 48 時間 にわたるローリング最適化をオンライン実行する。目的関数 J は、ガス暖房費 Cgas(τ) · Q̇heat(τ) 、LED 補光電力費 Celec(τ) · Pled(τ) 、および CO2 施用コストの総和から、純同化光合成速度に基づく市場性バイオマス蓄積価値 Pcrop · (dBiomass / dτ)(Anet) を差し引き、さらに生理障害ペナルティ項 ∑ Penalty(x(τ)) を最小化する経済制御問題として定式化される。

minu ∈ U ∫tt+Hp [ Cgas(τ) · Q̇heat(τ) + Celec(τ) · Pled(τ) + Cco2 · ṁco2(τ) - Pcrop · (dBiomass / dτ)(Anet) ] dτ + ∑ Penalty(x(τ))

ただし、収益最大化を優先するあまり作物生理限界を逸脱しないよう、MPC 最適化の内部には以下の非交渉的 ( Non-Negotiable ) な状態制約がハード拘束条件として課される。

  • 温度境界制約 : 施設内気温 Tmin ≤ Tin(τ) ≤ Tmax (トマト果菜類標準例 : 15.0 °C ≤ Tin ≤ 27.0 °C ) を厳守し、花粉不稔および低温障害を回避する。
  • VPD 生理窓制約 : 0.5 kPa ≤ VPD(τ) ≤ 1.5 kPa を維持し、過湿による灰色かび病発症と過乾燥による気孔閉鎖・尻腐れ症 ( BER ) を同時に抑止する。
  • 温度変化率制約 : | ΔT / Δt | ≤ 2.0 °C / hour に制限し、急激な温湿度ランプ変動に伴う果実膨圧急変と裂果を防止する。

4. 電力スポット市場 (EPEX SPOT / JEPX) 連動による DLI 動的負荷シフト

高軒高フェンロー温室で高出力 LED 同化補光 ( 200 – 350 μmol·m-2·s-1 ) を運用する場合、電力単価は最大級の変動運営費 ( OPEX ) となる。AI-MPC は欧州電力取引所 EPEX SPOT Day-Ahead または日本の JEPX スポット市場 の 1 時間値価格フィードを API で自動取得し、電力需要ピークに伴う高単価帯 ( 例 : 17:00 – 20:00 ) には補光 LED を自動的に減光または遮断する。

その一方で、植物光合成の積算応答特性を活用して電力単価が底値またはマイナス料金となる深夜時間帯 ( 01:00 – 06:00 ) や太陽光余剰時間帯へフォトン照射スケジュールを動的にシフト ( Load Shifting ) する。結果として、目標日積算光量 DLI = 30.0 mol·m-2·day-1 を 100 % 充足しながら、補光電気料金を 18 % – 26 % 削減する経済的裁定を無人で完結させる。

5. 従来 PID 制御 vs AI-MPC 定量ベンチマーク & 1.0 ha 導入投資回収・国際補助金

商業規模 10,000 m2 ( 1.0 ha ) のフェンロー型温室における年間運用比較では、MPC の先行的蓄熱・換気最適化により一次暖房燃料消費が 14 % – 22 % 削減 されると同時に、気孔開度と温度積算の安定化により乾物収量が +5 % – +11 % 向上する。初期センサー・ゲートウェイ導入費約 42,000 – 55,000 EUR / ha ( 約 680 万 – 890 万円 ) に対する単純投資回収期間はおおむね 1.2 – 1.8 年 となり、各国補助金制度を組み合わせることで CAPEX 負担をさらに圧縮できる。

補助金活用の面では、ドイツでは連邦食糧農業省 BLE / FNR 農業エネルギー効率向上プログラム が高度な計測制御・最適化コンピューター ( MSR / MPC ) および保温カーテン連携改修に対し 投資額の 40 % – 50 % を補助する。オランダでは税制優遇 EIA ( Energie-investeringsaftrek ) および官民共同研究プログラム Kas als Energiebron ( エネルギー源としての温室 ) が普及を後押しし、日本国内でも農林水産省 ( MAFF ) の みどりの食料システム戦略・スマート農業技術導入支援 を通じた高度環境制御システム導入補助の活用が可能である。設計試算には当ラボの 暖房負荷・カーテン省エネ計算機、EPEX SPOT 電力裁定シミュレーター、VenloCAD 3D 構造設計ツール、および 世界 8 か国 192 農業補助金ナビゲーター を直接連携して検証できる。

施設園芸エンジニアリング 実践FAQ

Q1: AI モデル予測制御 (MPC) が従来の PID 気候コンピューターより暖房費を 14–22 % 削減できる物理的理由は？
PID 制御は室内の温度や湿度が設定値から外れてから換気窓や暖房弁を動かす事後対応であるため、オーバーシュートや暖房直後の換気ロスが頻発します。MPC は 24–48 時間の気象予報と状態空間エネルギー収支 ODE を 5 分ごとに解くことで、日射が弱まる夕方のカーテン閉鎖タイミングや日中の自然予熱を先読みし、U 値 ( 6.5 → 2.2 W/(m²·K) ) とパイプ温度を最適調和させるため 14–22 % の一次エネルギー削減を実現します。

Q2: 日没前 45 分間の段階的換気パージはどのように灰色かび病 (Botrytis) と裂果を防ぎますか？
日没時に外気温が急低下すると温室内の飽和水蒸気圧が下がり、相対湿度が急上昇して作物表面が露点に達します。MPC は相対湿度 85 % 超過を待たずに日没 45 分前から徐々に天窓を開放して絶対湿度 x_in を先行排出し、VPD を 0.8–1.2 kPa の安全帯に保つと同時に温度変化率を 2.0 °C/h 以下に抑制するため、冷気ショックや果実の膨圧裂果を招かずに結露と灰色かび病を抑制できます。

Q3: EPEX SPOT や JEPX の時間別電力価格を用いた LED 補光シフトで光合成収量は落ちませんか？
果菜類や葉菜類のバイオマス蓄積は 24 時間単位の日積算光量 ( DLI、例 : 30 mol·m⁻²·d⁻¹ ) と葉面温度積算の整合性に大きく支配されます。MPC のコスト関数 J は高価格帯 ( 17:00–20:00 ) の LED 出力を抑制する代わりに深夜〜早朝の低単価帯 ( 01:00–06:00 ) へ必要フォトン量を自動再配分するため、目標 DLI と収量を維持したまま補光電力コストだけを 18–26 % 削減できます。

Q4: ドイツの BLE/FNR や日本の農林水産省 (MAFF) 補助金では AI-MPC 導入がどのように支援されますか？
ドイツの BLE/FNR エネルギー効率プログラムでは温室用計測・制御最適化システム ( MSR / AI-MPC ) や省エネカーテン改修に最大 40–50 % の補助金が交付されます。オランダの EIA や日本の MAFF スマート農業・産地生産基盤パワーアップ事業でも、省エネルギー率と生産性向上を定量証明できる高度環境制御機器が補助対象として認められます。
