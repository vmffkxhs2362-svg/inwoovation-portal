Vol. 53: バイオマス熱電併給 (CHP / BHKW) の SCR 排ガス浄化と生源 CO2 直接施用の熱力学・触媒工学

🌐 Vol. 53 Editions: 🇬🇧 English Edition → 🇩🇪 Deutsche Ausgabe → 🇯🇵 日本語版 (JA) (Active)
👨‍🔬 Inwoo Hwang (Inwoovation Lab)  |  📅 Last Updated: November 26, 2026  |  ⏱️ 14 min read · Biomasse-BHKW, SCR-DeNOx & CO2-Düngung

1. 施設園芸におけるバイオマス CHP (BHKW) のエネルギー収支と潜熱回収

ドイツ・ニュルンベルクのクノーブラウフスラント ( Knoblauchsland ) やニーダーライン・シュトラエレン ( Straelen ) 、オランダ・ウェストラント ( Westland ) などの欧州先進園芸クラスターでは、化石天然ガス燃焼式の熱電併給設備 ( CHP / BHKW ) から、木質チップおよびペレットを燃料とする バイオマス熱電併給システム ( Biomass Combined Heat and Power ) への転換が急速に進んでいる。大型フェンロー型連棟温室 ( Venlo Glasshouse ) のエネルギー設計において、バイオマス CHP は単なるベースロード暖房熱源および売電・自家消費電源にとどまらず、燃焼排ガス中の再生可能カーボンを光合成基質として回収する 生源 CO2 直接施用 ( Biogenic CO2 Direct Enrichment ) の中核インフラとして機能する。

木質チップガス化エンジンまたは蒸気タービン／ORC ( Organic Rankine Cycle ) 発電機を備えた 1.0 MWth 級バイオマス BHKW では、低位発熱量 ( LHV / Hu ) 基準で発電効率 ηel = 24 % – 30 % 、温水熱回収効率 ηth = 58 % – 64 % を達成し、さらに還水温度 55 °C 以下の低温熱交換器を用いた 排ガス凝縮潜熱回収 ( Flue Gas Condenser ) を組み込むことで総合一次エネルギー効率 ηtotal ≥ 88 % – 96 % ( NCV 基準 ) に到達する。同時に、排ガス中の水蒸気を露点以下へ冷却・凝縮分離することで、後段の触媒層および温室供給ダクト内の酸露点腐食と過剰加湿を同時に防止する。

m_dot_CO2_bio = m_dot_fuel · w_C · (44.01 / 12.011) · η_capture [kg CO2 · h⁻¹]
Q_total = Q_sensible + Q_latent = m_dot_fg · c_p · (T_in - T_out) + m_dot_cond · h_fg(T_dew)

乾燥基準の炭素含有率 wC = 0.48 – 0.50 kg C / kg dry wood の木質バイオマス 1.0 t ( 含水率 25 % ) を完全燃焼・精製した場合、理論生成量 1,350 kg CO2 のうち回収率 ηcapture = 85 % – 92 % で 約 1,150 – 1,240 kg の生源 CO2 を日中光合成ピーク帯へ供給でき、市販液化 CO2 ボンベ ( 180 – 320 EUR/t CO2 ) の購入コストを実質ゼロ近傍まで圧縮する。

2. 植物毒性ガス (Phytotoxizität) の許容閾値と連続ガス監視体制

固形バイオマスの不完全燃焼または高温窒素酸化によって生じる生排ガスには、微粒子煤塵 ( PM ) 、一酸化炭素 ( CO ) 、窒素酸化物 ( NO および NO2 ) 、二酸化硫黄 ( SO2 ) 、および極めて強い植物ホルモン作用を持つ微量 エチレン ( C2H4 ) が含まれる。トマト、パプリカ、キュウリなどの果菜類はガス状植物毒に対して極めて敏感であり、施設内注入前には厳格な連続分析計 ( FTIR / NDIR / 電気化学セル ) によるインターロック管理が不可欠となる。

とりわけ植物体への影響が深刻な 二酸化窒素 ( NO2 < 0.05 ppm ) および エチレン ( C2H4 < 5 – 10 ppb ) については、設定上限を超過した瞬間に 0.5 秒以内でバイパスダンパーを切り替え、煙突側へ全量緊急放出する フェイルセーフ ( Fail-Safe ) 二重遮断弁を実装する必要がある。

3. 高温セラミック集塵・SCR 脱硝・Pt/Pd 酸化触媒の多段浄化アーキテクチャ

バイオマス排ガスを植物群落へ安全に導入するための触媒浄化トレインは、上流から ① サイクロンおよび 220 – 320 °C 耐熱セラミックフィルターによるフライアッシュ除去、② 280 – 400 °C の最適反応温度窓で運転される 選択的触媒還元法 ( SCR: Selective Catalytic Reduction ) 、③ 下流の 白金・パラジウム ( Pt / Pd ) アルミナ担持酸化触媒 ( Oxikat ) 、④ 55 °C 還水による排ガス凝縮熱交換器および静電ミストエリミネーターで構成される。

4 NO + 4 NH3 + O2 →( V2O5-WO3/TiO2 , 280–400 °C ) 4 N2 + 6 H2O [DeNOx ≥ 95 %]
C2H4 + 3 O2 →( Pt / Pd / Al2O3 ) 2 CO2 + 2 H2O [残留 CO & C2H4 完全酸化]

SCR 反応では 32.5 % 尿素水 ( AdBlue / CO(NH2)2 ) を排ガス流路へ精密噴霧し、加水分解により生じたアンモニア ( NH3 ) をハニカム構造の五酸化バナジウム・三酸化タングステン担持酸化チタン ( V2O5-WO3/TiO2 ) 触媒上で窒素酸化物と化学量論比 1 : 1 に近い領域で反応させる。このとき未反応アンモニアのリーク ( NH3 スリップ < 2 ppm ) が温室内に流入すると葉面アルカリ障害と硝酸塩異常蓄積を招くため、下流にアンモニアスリップ触媒 ( ASC ) と Pt/Pd 酸化触媒を直列配置し、エチレン・CO・残存炭化水素を完全に CO2 と水蒸気へ転化する。

なお、木質燃料中のカリウム ( K ) やナトリウム ( Na ) 、塩素 ( Cl ) はバナジウム触媒の活性点を化学被毒させるため、バーク (樹皮) 比率を抑えた DIN EN ISO 17225-4 準拠の低灰分ウッドチップ ( 灰分 < 1.5 % ) の選定と、14 日周期の圧力損失 ( ΔP ) トレンド監視および年 1 回の圧縮空気パルス洗浄が長期触媒寿命 ( 24,000 – 32,000 運転時間 ) を担保する。

4. FvCB 光合成動力学・群落配管施用およびカスケード MPC/PID 制御

精製された生源 CO2 ガス ( CO2 濃度 10 – 14 vol% 、出口温度 35 – 42 °C ) は、外気空気との混合希釈ブロワーを経て、栽培ガッター ( 養液栽培ベンチ ) 直下に敷設された レーザー穿孔ポリエチレン薄膜チューブ ( Folientransportschläuche / CO2 Micro-Ducts ) を通じて群落内部へ均等分配される。これにより温室内の周辺 CO2 濃度を大気基準 420 ppm から光合成最適域である 850 – 1,000 ppm へと精密に引き上げる。

A = min( Ac , Aj ) - Rd = Vcmax · ( Ci - Γ* ) / [ Ci + Kc · ( 1 + O / Ko ) ] - Rd
dXstate / dt = Asys · Xstate + Bcontrol · Uactuator + Edisturbance · Dambient

Farquhar-von Caemmerer-Berry ( FvCB ) の C3 植物光合成生化学モデルに従い、葉肉細胞間隙 CO2 分圧 Ci が 300 ppm から 700 ppm へ上昇すると、ルビスコ ( RuBisCO ) のカルボキシル化速度 Vc が飛躍的に増大すると同時に酸素添加反応による 光呼吸 ( Photorespiration, Vo ) が劇的に抑制される。日積算光量 DLI > 18 mol·m⁻²·d⁻¹ の中〜高日射条件下では、純同化速度 A が +28 % – 35 % 向上する。

  • 外気換気連動型 MPC 最適化 ( 予測ホライズン Hp = 24 h , ステップ Δt = 300 s ): 天窓開度増大に伴う換気回数 ( ACH ) の急増時にはガス漏れ損失が指数的に増加するため、モデル予測制御 ( MPC ) が限界利益 ( 収量増収益 - ブロワー動力費 ) を計算し、目標濃度を 1,000 ppm から 550 – 650 ppm へ動的に引き下げる。
  • インナー PID ループとセンサー校正 SOP ( Δt = 1 – 5 s ): 2 波長非分散赤外線 ( Dual-Beam NDIR ) CO2 センサー ( ±15 ppm ) 、アスピレーション式 PT1000 温度計 ( ±0.15 °C ) 、および FTIR 排ガス安全計を 14 日間隔でゼロ／スパン校正し、カルマンフィルター残差 |rk| > 3σ 検知時には隣接ゾーン冗長センサーへ無衝撃切替 ( Bumpless Transfer ) を行う。

施設園芸エンジニアリング 実践FAQ

Q1: 木質チップ・バイオマス CHP (BHKW) で総合一次エネルギー効率 η_total ≥ 88% を達成しつつ生源 CO2 を回収する熱力学構成は？
1.0 MWth 級の木質バイオマス熱電併給では、発電効率 η_el = 24–30% および温水熱回収効率 η_th = 58–64% に加え、暖房還水温度 55 °C 以下の排ガス凝縮潜熱回収器 (Flue Gas Condenser) を直列配置することで総合一次エネルギー効率 η_total ≥ 88%（最大 96%、低位発熱量 NCV 基準）を達成し、含水率 25% の木質チップ 1.0 t あたり約 1,150–1,240 kg の生源 CO2 を回収できます。

Q2: V2O5-WO3/TiO2 SCR 脱硝触媒と Pt/Pd 酸化触媒の温度窓および果菜類の植物毒性インターロック閾値は？
上流の 220–320 °C 高温セラミックフィルターで灰分を除塵した後、280–400 °C の温度窓で尿素水を噴霧して V2O5-WO3/TiO2 ハニカム SCR 触媒により NOx を 95% 以上還元し、続く Pt/Pd アルミナ酸化触媒 (Oxikat) で未燃炭化水素を完全酸化します。施設注入時は NO2 < 0.05 ppm（全 NOx < 5 ppm）、落花を防ぐエチレン C2H4 < 5 ppb、CO < 5 ppm、SO2 < 0.1 ppm、NH3 スリップ < 2 ppm を連続監視し、超過時は 0.5 秒以内にバイパス煙突へ全量遮断します。

Q3: 高軒高フェンロー温室で天窓を開放する日中時間帯に、FvCB モデルと MPC で CO2 施用を最適化する制御ロジックは？
Farquhar-FvCB 光合成モデルに基づき、天窓閉鎖・微換気時には RuBisCO カルボキシル化速度を高めて光呼吸を抑制する 850–1,000 ppm を維持し（純同化速度 +28–35% 向上）、日射上昇に伴い天窓換気回数 (ACH) が増大する局面ではモデル予測制御 (MPC: ホライズン 24 h、周期 300 s) が CO2 逸散損失と限界増収収益を逐次比較して目標濃度を 550–650 ppm へ動的に引き下げます。
