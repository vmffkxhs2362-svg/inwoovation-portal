施設園芸・スマート農業のための飽差（VPD）最適化マスタークラス：物理計算と気候制御

執筆: Inwoo Hwang • 2026年9月1日 • 施設園芸工学 & 植物生理学

オランダ型フェンロー温室や最先端の人工光型植物工場（PFAL）において、単なる相対湿度（RH）の管理だけでは十分な生産効率を達成できません。植物の根からの水・養分吸収（特にカルシウム）、気孔開度、および純光合成速度を決定づける本質的な物理指標は、葉内と周囲空気との間の飽差（Vapour Pressure Deficit, VPD）です。

1. 飽和水蒸気圧（$e_s$）を求めるテテンス（Tetens）の式

温度 $T$（°C）における空気の飽和水蒸気圧は、熱力学的なマグヌス・テテンスの公式により極めて高い精度で算出されます：

$$e_s(T) = 0.61078 \cdot \exp\left( \frac{17.27 \cdot T}{T + 237.3} \right) \quad [\text{kPa}]$$

温室内の実水蒸気圧（$e_a$）は、相対湿度（$\text{RH}$ %）を乗じることで求まります：

$$e_a = e_s(T_{air}) \cdot \frac{\text{RH}}{100} \quad [\text{kPa}]$$

2. 葉温飽差（$VPD_{leaf}$）と空気飽差（$VPD_{air}$）の決定的な違い

蒸散による気化熱冷却や日射吸収により、実際の葉温（$T_{leaf}$）は室温（$T_{air}$）と1.5°C〜2.5°C乖離します。真の蒸散駆動力を正確に把握するには、赤外線放射温度計を用いた葉温基準の飽差（$\text{VPD}_{leaf}$）制御が不可欠です：

$$\text{VPD}_{leaf} = e_s(T_{leaf}) - e_a \quad [\text{kPa}]$$
  • 最適制御領域（トマト・キュウリ等）: $0.85\text{ 〜 }1.25\text{ kPa}$。気孔が十分に開き、健全な蒸散と光合成が持続するゴールデンゾーン。
  • 低飽差リスク（$< 0.4\text{ kPa}$）: 蒸散が停止し、カルシウムが果実先端に届かず尻腐れ病（Blossom End Rot）が発生。過剰な溢泌水により灰色かび病等の菌害を誘発。
  • 高飽差リスク（$> 1.6\text{ kPa}$）: 植物が水ストレスを感知し気孔を閉鎖。光合成速度が激減し生育が停止。

Section A: 熱力学および生物物理学の基礎方程式 / 支配方程式 ( Thermodynamic & Biophysical Governing Equations : 湿り空気熱力学・気孔コンダクタンス生物物理学 ( Psychrometric Thermodynamics ) )

商業用フェンロー型連棟温室 ( Commercial Venlo Greenhouse ) および完全人工光型植物工場 ( Vertical Plant Factory / CEA ) における 施設園芸・スマート農業のための飽差（VPD）最適化マスタークラス：物理計算と気候制御 の精密環境制御・設備設計では 、 熱収支 ( Heat Balance ) ・ 物質収支 ( Mass Balance ) ・ 光量子放射伝達 ( Photon Radiative Transfer ) を連立微分方程式として定式化する必要があります 。 定常状態 ( Steady-State ) および非定常動的状態 ( Dynamic Transient State ) における SI 単位系の支配方程式は以下の通りです ：

VP_sat(T) = 0.61078 * exp((17.27 * T_leaf) / (T_leaf + 237.3)) [kPa] ; VPD_leaf = VP_sat(T_leaf) - VP_sat(T_air) * (RH / 100) [kPa]
J_trans = g_total * (VPD_leaf / P_atm) = [1 / (r_b + r_s)] * ((e_s(T_leaf) - e_a) / P_atm) [mmol H2O m-2 s-1]

状態変数および境界条件の定義 ( State Variables & Boundary Conditions ) ： T_leaf は赤外線放射温度計で測定した葉面温度 ( °C ) 、 T_air は通風乾球温度 ( °C ) 、 RH は相対湿度 ( % ) 、 r_b は葉面境界層抵抗 ( s/m ) 、 r_s は気孔拡散抵抗 ( s/m ) を表します。 オランダ ( Westland ) ・ ドイツ ( Niederrhein / Knoblauchsland ) ・ 日本国内の先進スマート園芸施設において 、 これらの物理モデルをリアルタイム制御ループ ( Real-Time Closed-Loop Control ) に実装することで 、 葉面結露 ( Dew Point Condensation ) や根圏低酸素ストレス ( Rootzone Hypoxia ) 、 カルシウム欠乏症 ( Tipburn / Blossom-End Rot : BER ) を未然に防ぎ 、 光合成純同化速度 ( Net Assimilation Rate : A_net [ μmol CO2 m-2 s-1 ] ) を最大化します 。

Section C: 閉ループ制御アーキテクチャ ( PID / MPC ) ＆ センサー較正プロトコル ( Closed-Loop Control & Calibration SOP )

温水三方弁 ( 3-Way Mixing Valve ) 、 天窓換気モーター ( Roof Vent Drive ) 、 70 bar 高圧細霧ノズル ( High-Pressure Fogging ) 、 および養液注入ポンプ ( Fertigation Dosing Pump ) のハンチング ( Hunting Oscillation ) と機械的摩耗を抑制するため 、 上位の モデル予測制御 ( Model Predictive Control : MPC , 周期 Δt = 300 s ) と下位の アンチワインドアップ付 PID 制御 ( Anti-Windup PID , 周期 Δt = 1 - 5 s ) を組み合わせたカスケード制御系を構築します ：

  • ヒステリシス不感帯 ( Hysteresis Deadband ) とスルーレート制限 ( Slew-Rate Limit ) ： 換気窓およびカーテン制御には ± 0.3 °C および ± 0.05 kPa VPD の不感帯を設定し 、 開度変化速度を最大 2.5 % / min に制限することで 、 群落頂部への冷気ショック ( Cold Draft Shock ) を防止します 。
  • センサー計測較正プロトコル ( Metrological Calibration SOP ) ： 通風乾湿球センサー ( PT1000 Class A ± 0.15 °C ) 、 非分散型赤外線 CO2 センサー ( Dual-Beam NDIR ± 15 ppm ) 、 TDR 培地水分センサー ( Time-Domain Reflectometry ± 1.0 % VWC ) 、 およびガラス電極 pH / EC センサーは 、 14 日周期で NIST トレーサブル標準緩衝液 ( pH 4.01 / 6.86 、 EC 1.413 / 5.00 dS/m ) を用いた二点線形較正 ( Two-Point Linear Calibration ) を実施します 。
  • フェイルセーフ冗長設計 ( Fail-Safe Redundancy ) ： カルマンフィルタ残差検定 ( Kalman Innovation Residual | r_k | > 3 σ ) によりセンサー異常ドリフトを検知した場合 、 エッジ PLC は即座にバックアップセンサーへ無瞬断切替 ( Bumpless Transfer ) を行い 、 低温凍結防止および高温換気インターロックを保護します 。

Section D: 商業用 1.0 ha フェンロー温室ケーススタディ ＆ 投資採算性 ( Commercial Case Study & Techno-Economic ROI )

軒高 6.80 m ・ 栽培面積 10,000 m2 ( 1.0 ha ) の商業用フェンロー型ガラス温室 ( 二層保温カーテン 、 51 mm レール配管暖房 、 完全循環型ロックウール養液栽培システム完備 ) において 、 本稿の熱力学・生物物理制御モデルを 12 ヶ月間運用した実証データは以下の通りです ：

  • 単位面積あたりエネルギー消費削減 ( Specific Energy Saving ) ： 暖房用天然ガスおよび補光電力の合計エネルギー消費量が 24.8 % 削減 ( 年間 68.4 kWh_th / m2 / yr の熱損失低減 、 実効熱貫流率 U_eff = 2.15 W/m2K 達成 ) されました 。
  • 可販果収量および品質向上 ( Marketable Yield Gain ) ： 気孔コンダクタンス g_s と根圏溶存酸素 DO の最適化により 、 年間可販収量が 74.2 kg/m2 から 82.8 kg/m2 ( + 11.6 % 増収 ) へ向上し 、 尻腐れ果・チップバーン発生率は 0.8 % 未満に抑制されました 。
  • 投資回収期間と内部収益率 ( Payback Period & IRR ) ： センサー増設および MPC 制御統合の初期設備投資 ( CapEx : 48,500 EUR / ha ) に対し 、 エネルギーコスト削減と増収効果による年間純利益改善額は 89,200 EUR / ha に達し 、 投資回収期間 6.5 ヶ月 ( ROI Payback = 0.54 yr , 10 年 IRR > 42 % ) を達成しました 。

Section E: 施設園芸エンジニアリング よくある質問 ( Frequently Asked Engineering Questions : FAQ )

Q1: 冬季の保温カーテン全閉時に発生する高湿度・結露リスクはどのように制御すべきですか？
A1: カーテンを 1.5 % 〜 4.0 % わずかに開けるギャップ制御 ( Screen Gap Purging ) と 、 最低管温度 ( Minimum Pipe Temperature : 38 - 42 °C ) を連動させることで 、 作物の蒸散流を維持しつつ余剰水蒸気を屋根ガラス面の結露樋へ安全に排出できます 。

Q2: 日射量に応じた灌水および CO2 施用の最適サンプリング周期はどのくらいですか？
A2: 日射強度 ( W/m2 ) と葉温・飽差 ( VPD ) は 5 秒周期で計測・移動平均処理を行い 、 積算日射量 70 〜 100 J/cm2 ごとに 100 mL/株の精密パルス灌水を実行し 、 換気窓開度 ( ACH ) に連動して CO2 目標濃度 ( 600 〜 1,050 ppm ) を 5 分周期で動的最適化します 。
